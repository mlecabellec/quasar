# Feature 0220 [PHASED OUT]

> **Note:** This feature has been phased out as per directive [TSK-20260410-006]. The `librdkafka` dependency and related build system integrations have been removed.

## Title

Provide high-performance Apache Kafka integration for distributed event streaming.

## Description

The system shall provide Kafka producer and consumer capabilities, enabling streaming of system state and telemetry to big data platforms and cloud-native services. Kafka entities are integrated into the `ActiveEntity` lifecycle.

The following capabilities and features shall be provided:

- [FE-0220.1] **Kafka Stack Integration**
    - [FE-0220.1.1] Integrate `librdkafka` into the build system.
- [FE-0220.2] **Kafka Producer Entity**
    - [FE-0220.2.1] Create `KafkaProducer` inheriting from `ActiveEntity`.
    - [FE-0220.2.2] Support asynchronous message delivery with delivery report callbacks.
    - [FE-0220.2.3] Expose metrics (queue length, error counts, latency) as reflexive fields.
- [FE-0220.3] **Kafka Consumer Entity**
    - [FE-0220.3.1] Create `KafkaConsumer` inheriting from `ActiveEntity`.
    - [FE-0220.3.2] Support Consumer Groups and automatic offset management.
    - [FE-0220.3.3] Integrate with the `IObserver` pattern to notify components of incoming messages.
- [FE-0220.4] **Tree Serialization & Framing**
    - [FE-0220.4.1] Support serializing `NamedObject` hierarchies to JSON or Binary for Kafka payloads.
    - [FE-0220.4.2] Support Kafka headers for metadata (e.g., system ID, timestamps).
- [FE-0220.5] **Security and Reliability**
    - [FE-0220.5.1] Support SASL/SSL authentication and encryption.
    - [FE-0220.5.2] Implement configurable retry policies and local buffering.
- [FE-0220.6] **Scripting**
    - [FE-0220.6.1] Expose Kafka producer/consumer APIs to Lua as a dedicated plugin.

Project shall be located in `cmake-projects/kafka`.
