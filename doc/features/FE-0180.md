# Feature 0180

## Title

Provide high-performance asynchronous networking capabilities for the scripting environment.

## Description

The system shall provide a networking plugin that allows creating and interacting with TCP, UDP, HTTP, HTTPS, and WebSocket services directly from Lua scripts.

The following capabilities and features shall be provided:

- [FE-0180.1] **TCP/UDP Server & Client Support**
    - [FE-0180.1.1] Expose `TCPServer`, `TCPSession`, and `TCPClient` to Lua.
    - [FE-0180.1.2] Expose `UDPServer` and `UDPClient` to Lua.
    - [FE-0180.1.3] Map C++ server/client callbacks (e.g., `onConnected`, `onReceived`, `onError`) to Lua functions.
    - [FE-0180.1.4] Support unicast and multicast datagram communication.
- [FE-0180.2] **Web Protocols (HTTP/HTTPS/WS)**
    - [FE-0180.2.1] Provide an `HTTPServer` with Lua-based request handling and RESTful API building blocks (`HTTPRequest`, `HTTPResponse`).
    - [FE-0180.2.2] Provide a WebSocket gateway for real-time full-duplex communication (WS/WSS).
    - [FE-0180.2.3] Implement asynchronous web clients for interacting with external APIs.
- [FE-0180.3] **Security and SSL/TLS**
    - [FE-0180.3.1] Support SSLContext configuration in Lua (certificates, private keys, peer verification).
    - [FE-0180.3.2] Provide encrypted communication (HTTPS, WSS, Secure TCP).
- [FE-0180.4] **Integration**
    - [FE-0180.4.1] Organize components under the `quasar.net.server` and `quasar.net.client` namespaces.
    - [FE-0180.4.2] Integrate with the `scripting` plugin system via `registerPluginComponents`.

Components shall be based on `asio` and `CppServer` libraries.

Project shall be located in `cmake-projects/scripting/plugins/net`.
