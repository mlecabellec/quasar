# Feature 0100

## Title

Provide a standard library of protocol definitions (EdgeBase).

## Description

The system shall provide pre-defined schemas and implementations for common network and data protocols, leveraging the Datacodec framework.

The following capabilities and features shall be provided:

- [FE-0100.1] Internet Protocol Suite
    - [FE-0100.1.1] Support **UDP** (User Datagram Protocol) header parsing and payload handling.
    - [FE-0100.1.2] Support **TCP** (Transmission Control Protocol) header parsing.
    - [FE-0100.1.3] Support **IPv4** (Internet Protocol version 4) header parsing.
    - [FE-0100.1.4] Support **Ethernet II** frame header parsing.

- [FE-0100.2] Space Data System Standards (CCSDS)
    - [FE-0100.2.1] Support **CCSDS Telecommand (TC)** packet parsing.
    - [FE-0100.2.2] Support **CCSDS Telemetry (TM)** packet parsing (Source Packets).

- [FE-0100.3] Automotive / Automation Protocols
    - [FE-0100.3.1] Support **CAN** (Controller Area Network) frame structures.

- [FE-0100.4] Utility Protocols
    - [FE-0100.4.1] Support **IENA** protocol format.
    - [FE-0100.4.2] Support **ESVF** format.

Each protocol implementation shall provide:
- A reusable `ContainerDef` (Schema) matching the standard specification.
- Logic for standard header field manipulation (e.g., length calculation, checksums where applicable).

Project shall be located in cmake-projects/edgebase (or integrated into datacodec-protocols).

## Expected result

A collection of ready-to-use protocol schemas that allow immediate parsing of standard network traffic.
