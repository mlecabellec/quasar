# Feature 0230

## Title

Provide a remote monitoring and control interface via REST and WebSocket API.

## Description

The system shall provide a lightweight, high-performance REST and WebSocket API for real-time remote monitoring, tree traversal, value querying, and interactive method invocation on `NamedObject` hierarchies and `ActiveEntity` components. There are no built-in graphical user interface (GUI) dashboard or asset-hosting requirements.

The following capabilities and features shall be provided:

- [FE-0230.1] **Lightweight REST API**
    - [FE-0230.1.1] Traversal endpoints (`GET /api/v1/walk?path=...`) supporting stateless chunked responses.
    - [FE-0230.1.2] Metadata endpoints (`GET /api/v1/meta?path=...`) to query node details.
    - [FE-0230.1.3] Value modification endpoints (`PATCH /api/v1/objects/{id}`) to safely modify primitive values.
    - [FE-0230.1.4] Dynamic OpenAPI documentation endpoints (`GET /openapi.json`) dynamically resolving current tree structures.
- [FE-0230.2] **Real-time Synchronization (WebSocket)**
    - [FE-0230.2.1] Non-secure and secure WebSocket server endpoints (`LuaWSServer` and `LuaSecureWSServer`).
    - [FE-0230.2.2] Push incremental tree delta updates to registered clients based on prefix subscriptions.
- [FE-0230.3] **Lua Scripting bindings**
    - [FE-0230.3.1] Bind all server capabilities into the `quasar.net` scripting modules.
    - [FE-0230.3.2] Support lifecycle callback hooks for dynamic script execution on WS connections.

The implementation is located within the `scripting/plugins/net` and `named` modules.
