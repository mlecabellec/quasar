# Feature 0230

## Title

Provide a remote monitoring and control interface via Web UI and REST/WebSocket API.

## Description

The system shall provide a streamlined, high-performance Web UI and a corresponding REST/WebSocket API for real-time remote monitoring, data visualization, and interactive control of the system's `NamedObject` hierarchy and `ActiveEntity` components.

The following capabilities and features shall be provided:

- [FE-0230.1] **Web UI Service**
    - [FE-0230.1.1] Provide a `WebUIService` inheriting from `ActiveEntity`.
    - [FE-0230.1.2] Support hosting static assets and dynamic API endpoints (HTTP/HTTPS).
- [FE-0230.2] **Real-time Synchronization**
    - [FE-0230.2.1] Implement a WebSocket gateway for pushing `NamedObject` updates to connected clients.
    - [FE-0230.2.2] Provide real-time data visualization (e.g., history graphs for numeric values).
- [FE-0230.3] **Interactive Dashboard**
    - [FE-0230.3.1] Provide a hierarchical tree view for navigating the `NamedObject` registry.
    - [FE-0230.3.2] Support viewing and editing object values (Integer, Boolean, String) with validation.
    - [FE-0230.3.3] Provide a control center for listing and invoking reflexive methods on `ActiveEntities`.
- [FE-0230.4] **REST API**
    - [FE-0230.4.1] Provide comprehensive REST API endpoints (GET, PATCH, POST) for external clients.
    - [FE-0230.4.2] Provide iterative OpenAPI (Swagger) documentation.

Project shall be located in `cmake-projects/webui`.
