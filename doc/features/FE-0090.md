# Feature 0090

## Title

Provide a binary data serialization and deserialization library (Datacodec).

## Description

The library shall provide a flexible framework for defining binary data schemas and codec strategies, enabling transformation between binary buffers and high-level named object hierarchies.

The following capabilities and features shall be provided:

- [FE-0090.1] Codec Interface (`ICodec`)
    - [FE-0090.1.1] Define an abstract interface for encoding and decoding values to/from a `BitBufferSlice`.
    - [FE-0090.1.2] Support querying fixed or dynamic bit sizes of encoded data.

- [FE-0090.2] Primitive Codecs
    - [FE-0090.2.1] Provide an `IntegerCodec` supporting various bit-widths and endianness, mapping to `NamedInteger`.
    - [FE-0090.2.2] Provide a `FloatCodec` supporting IEEE-754 single and double precision, mapping to `NamedFloatingPoint`.
    - [FE-0090.2.3] Provide a `StringCodec` supporting fixed-length (padded) and variable-length (null-terminated) strings.

- [FE-0090.3] Schema Definition
    - [FE-0090.3.1] Provide a `FieldDef` class to bind a name, a codec, and a bit-offset into a schema definition.
    - [FE-0090.3.2] Provide a `ContainerDef` class to aggregate multiple fields into a composite structure.
    - [FE-0090.3.3] Support nested containers for complex hierarchical data models.

- [FE-0090.4] Advanced Schema Features
    - [FE-0090.4.1] Provide `ConditionalFieldDef` to support dynamic presence of fields based on runtime conditions (e.g., values of other fields).
    - [FE-0090.4.2] Provide `TransformCodec` (or Calibration mechanism) to support value transformation during encoding/decoding (e.g., Raw to Engineering value conversion via linear or polynomial functions).
    - [FE-0090.4.3] Support `Actions` or Hooks triggered pre-encoding or post-decoding for custom logic integration.

- [FE-0090.5] Binary Mapper
    - [FE-0090.5.1] Provide a mechanism to fully decode a `BitBufferSlice` into a `NamedObject` hierarchy based on a `ContainerDef` schema.
    - [FE-0090.5.2] Provide a mechanism to encode a `NamedObject` hierarchy into a `BitBufferSlice` based on a `ContainerDef` schema.

- [FE-0090.6] External Schema Configuration
    - [FE-0090.6.1] Support defining schemas using standard serialization formats (JSON, XML).
    - [FE-0090.6.2] Provide parsers to load `ContainerDef` and `FieldDef` structures from these external configuration files (e.g., `.edge.json`).

Classes shall be associated with "datacodec" namespace (or its underlying dependencies in "quasar::coretypes" and "quasar::named").

Project shall be located in cmake-projects/datacodec.

## Expected result

A C++ library capable of handling complex binary protocols defined via code or external configuration.
