# Feature 0040

## Title

Provide a modern C++23 EtherCAT Master library (Resoem) for real-time industrial communication.

## Description

The library shall provide a clean-room, modernized reimplementation of the Simple Open EtherCAT Master (SOEM), focusing on safety, readability, and integration with the Quasar project.

The following capabilities and features shall be provided:

- [FE-0040.1] **Transport Layer (Linux Raw Sockets)**
    - [FE-0040.1.1] Use Linux `AF_PACKET` sockets with `SOCK_RAW` for direct Ethernet frame access.
    - [FE-0040.1.2] Support configurable receive timeouts and interface-specific MAC address retrieval.
    - [FE-0040.1.3] Implement non-blocking send/receive operations with robust error handling via exceptions.

- [FE-0040.2] **EtherCAT Frame Management**
    - [FE-0040.2.1] Provide a `FrameBuilder` for constructing multi-datagram Ethernet frames.
    - [FE-0040.2.2] Support standard EtherCAT commands: APRD, APWR, APRW, FPRD, FPWR, FPRW, BRD, BWR, BRW, LRD, LWR, LRW, ARMW, and FRMW.
    - [FE-0040.2.3] Implement automatic "More" bit handling and frame padding to minimum Ethernet size (64 bytes).
    - [FE-0040.2.4] Support 32-bit logical addressing for process data exchange.

- [FE-0040.3] **Network Discovery & Enumeration**
    - [FE-0040.3.1] Automatically detect and count slaves on the wire using broadcast read.
    - [FE-0040.3.2] Assign configured station addresses (starting at 0x1001) to each slave.
    - [FE-0040.3.3] Parse the Slave Information Interface (SII/EEPROM) to identify Vendor ID, Product Code, Revision, and Name.
    - [FE-0040.3.4] Map network topology and establish parent-child relationships for each slave.

- [FE-0040.4] **Mailbox Protocols**
    - [FE-0040.4.1] **CoE (CANopen over EtherCAT)**:
        - [FE-0040.4.1.1] Support SDO Read/Write for expedited and normal transfers.
        - [FE-0040.4.1.2] Implement segmented SDO transfers for large data objects.
        - [FE-0040.4.1.3] Provide Object Dictionary (OD) browsing capabilities (Read OD List, Read OD Description).
    - [FE-0040.4.2] **FoE (File over EtherCAT)**:
        - [FE-0040.4.2.1] Implement file upload (Read) and download (Write) state machines.
        - [FE-0040.4.2.2] Support Bootstrap state transitions for firmware updates.
    - [FE-0040.4.3] **EoE (Ethernet over EtherCAT)**:
        - [FE-0040.4.3.1] Implement Ethernet frame fragmentation and reassembly according to ETG.1000.6.
        - [FE-0040.4.3.2] Support virtual network communication through EtherCAT mailboxes.

- [FE-0040.5] **Process Data (PDO) Configuration**
    - [FE-0040.5.1] Support PDO mapping retrieval from both SII categories and CoE (0x1C12/0x1C13).
    - [FE-0040.5.2] Automatically calculate and program FMMU (Fieldbus Memory Management Unit) entries for inputs and outputs.
    - [FE-0040.5.3] Manage a global `ProcessImage` buffer with bit-level accessors.
    - [FE-0040.5.4] Support cyclic data exchange using the `LRW` command for atomic read/write updates.

- [FE-0040.6] **Distributed Clocks (DC) Synchronization**
    - [FE-0040.6.1] Implement propagation delay measurement between slaves with nanosecond resolution.
    - [FE-0040.6.2] designate a Reference Clock (usually the first DC-capable slave) for the network.
    - [FE-0040.6.3] Provide cyclic drift compensation using the `ARMW` command to `0x0910`.
    - [FE-0040.6.4] Configure SYNC0/SYNC1 signals with specific cycle times and shift offsets.

- [FE-0040.7] **Resilience & Diagnostics**
    - [FE-0040.7.1] Implement "Hot-Connect" support via periodic status checks and automated slave recovery.
    - [FE-0040.7.2] Support mailbox retry logic for busy or slow-responding slaves.
    - [FE-0040.7.3] Provide human-readable diagnostic strings for SDO Abort codes and AL Status codes.

- [FE-0040.8] **Modern C++23 Implementation Standards**
    - [FE-0040.8.1] Use `std::expected` (Result<T>) for type-safe error handling instead of integer return codes.
    - [FE-0040.8.2] Use `std::span` for zero-copy views of communication buffers.
    - [FE-0040.8.3] Leverage `std::chrono` for all timeout and timing calculations.
    - [FE-0040.8.4] Employ packed structures and standard-compliant attributes for hardware register layouts.

## Expected Result

A static library `libresoem.a` and associated headers that allow a C++ application to fully control an EtherCAT network on Linux, from discovery to high-precision synchronized cyclic operation.
