# Goal

Implement a streamlined, high-performance Web UI and a corresponding REST/WebSocket API for the Quasar framework, enabling real-time remote monitoring, data visualization, and interactive control of the system's `NamedObject` hierarchy and `ActiveEntity` components.

# Details

## Context

As Quasar systems scale, the need for a centralized, accessible, and real-time dashboard becomes critical. This task focuses on bridging the C++ backend with modern web technologies to provide a "live view" of the system state. The architecture will involve a C++-based web server hosting a Single Page Application (SPA) and exposing industrial-grade APIs for third-party integration and real-time telemetry.

## Implementation Plan

1. **Backend Infrastructure**: 
    - Scaffold `cmake-projects/webui`.
    - Integrate `CppServer` and define the REST/WS routing logic.
    - Implement the `IObserver` bridge to capture `NamedObject` changes and route them to WebSockets.
2. **Frontend Development**:
    - Setup a React/TypeScript environment (or a pure JS solution if a zero-build-step approach is preferred for simplicity).
    - Implement the Tree Navigator and Detail View.
    - Build the Method Invocation modal.
3. **API Integration**:
    - Map `ActiveEntity::execute` calls to REST `POST` requests.
    - Implement WebSocket "Subscriptions" where the UI only receives updates for visible parts of the tree.
4. **Graphing Engine**:
    - Add a background circular buffer in the C++ service to store recent history for selected nodes.
    - Expose history data via REST for initial chart load and WebSockets for live updates.

# Test and validation

- **Synchronization Latency**: Verify that changes in C++ are reflected in the UI within 100ms over local network.
- **Concurrent Access**: Test the UI with 10 simultaneous browser sessions and verify backend stability.
- **REST Fidelity**: Use `curl` to verify all documented REST endpoints against expected results.
- **Method Execution**: Verify that complex parameter passing (e.g., JSON objects) correctly maps to `NamedObject` arguments in C++ and returns valid results.
- **Browser Compatibility**: Ensure the UI is functional and "fancy" on latest Chrome, Firefox, and Safari (Debian 12/13 environments).

## Expected result

A modern, responsive web dashboard that provides full transparency and control over the internal state of a Quasar system.
