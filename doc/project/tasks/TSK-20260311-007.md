# Goal

Implement Apache Kafka producer and consumer capabilities within the Quasar framework, enabling high-performance, distributed streaming of system state and telemetry to big data platforms and cloud-native services.

# Details

## Context

Apache Kafka is the industry standard for distributed event streaming. To support large-scale industrial IoT (IIoT) deployments, Quasar must be able to act as a reliable data source (Producer) and an active consumer of control events or configuration updates (Consumer) from Kafka clusters. This task focuses on providing a robust C++ implementation integrated with the `ActiveEntity` lifecycle and exposed via scripting plugins.

## Implementation Plan

1. **Stack Integration**: Add `librdkafka` to the build system. Create `cmake-projects/kafka` module.
2. **Wrapper Development**: Build thread-safe C++ wrappers for Kafka configuration, topics, and handles.
3. **Producer/Consumer Entities**:
    - Implement `KafkaProducer` with a high-level `publish(topic, key, payload)` API.
    - Implement `KafkaConsumer` with a background polling loop and event-driven notifications.
4. **Serialization Integration**: Connect with `quasar::named::serialization` to allow direct publishing of object trees.
5. **Scripting Bindings**: Map the entities to Lua using `sol2`, including support for asynchronous callbacks.

# Test and validation

- **Local Cluster Validation**: Run tests against a local Docker-based Kafka instance (or a mock broker).
- **Throughput Test**: Verify that the producer can handle sustained bursts of 10,000+ messages/sec without blocking core execution loops.
- **Consumer Rebalancing**: Verify that Quasar consumers correctly handle cluster rebalancing and partition assignment.
- **Resilience Test**: Simulate cluster disconnects and verify that the producer buffers data and resumes correctly upon reconnection.
- **Memory Safety**: Use ASan to verify clean cleanup of Kafka handles and memory during state transitions.

## Expected result

A high-performance Kafka integration module allowing Quasar systems to participate in large-scale distributed event streaming architectures.
