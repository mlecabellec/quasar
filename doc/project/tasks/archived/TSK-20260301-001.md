# Goal

Implement in namedobject library a complete deep copy mechanism for NamedObject and its derived classes.

# Details

## Context

NamedObject is a class that represents a named object in a hierarchical structure. It is used to store and manage named objects in a tree-like structure. The class is implemented in the quasar::named namespace.

## Requirements

- [TSK-20260301-001.1] Implement a deep copy mechanism for NamedObject and its derived classes. This deep copy shall be invoked with an explicit "deepCopy" method.
  - [TSK-20260301-001.1.1] The deepCopy method shall return a shared_ptr to a new NamedObject of the same type than the original.
  - [TSK-20260301-001.1.2] One variant of deepCopy method shall take no parameters and shall return a deep copy of the object assuming it is the root of the copied tree. In this case, the returned object shall have no parent.
  - [TSK-20260301-001.1.3] One variant of deepCopy method shall take two parameters that are the original parent and the new parent. In this case, the returned object shall have the new parent.
- [TSK-20260301-001.2] NamedBufferSlice that are based on a NamedBuffer that is their parent shall be transposed to their new parent.
- [TSK-20260301-001.3] NamedBufferSlice that are based on a NamedBuffer that is not their parent shall not be rebased.
- [TSK-20260301-001.4] NamedBufferSlice that are based on a NamedBufferSlice that is their parent shall be transposed to their new parent.
- [TSK-20260301-001.5] NamedBufferSlice that are based on a NamedBufferSlice that is not their parent shall not be rebased.
- [TSK-20260301-001.6] NamedBufferSlice can be constructed from a NamedBuffer.
- [TSK-20260301-001.7] NamedBufferSlice can be constructed from a NamedBufferSlice.
- [TSK-20260301-001.8] Out of bound access to NamedBuffer and NamedBufferSlice objects shall be detected and an exception shall be thrown.
- [TSK-20260301-001.9] Implement NamedBitBuffer and NamedBitBufferSlice classes on the same model than NamedBuffer and NamedBufferSlice classes but basing on BitBuffer and BitBufferSlice classes.
- [TSK-20260301-001.10] Implement deepCopy method for NamedBitBuffer and NamedBitBufferSlice classes.



## Implementation Plan

1. Analyze code from cmake-projects/named.
2. Verify that requirements of this task are not inconsistent with exisitng code or doc/features/FE-0020.md feature requirements
3. Implement capability to create NamedBufferSlice from a NamedBuffer or a NamedBufferSlice.
4. Implement a deep copy mechanism for NamedObject and its derived classes. All derivated classes shall also implement the deepCopy method.
5. Implement test cases.
6. Clean, build, run tests.
7. Update doc/features/FE-0020.md feature requirements to include the new capabilities.


# Test and validation


1. Create multiple test cases verifying the capability to create NamedBufferSlice from a NamedBuffer or a NamedBufferSlice.
    1.1 Verify ability to created arbitrary NamedBuffer objects.
    1.2 Verify ability to created arbitrary NamedBufferSlice objects.
    1.3 Verify ability to created arbitrary NamedBufferSlice objects from a NamedBuffer object.
    1.4 Verify ability to created arbitrary NamedBufferSlice objects from a NamedBufferSlice object.
    1.5 Verify out of bound access to NamedBuffer and NamedBufferSlice objects. No out of bound access shall be allowed and no out of bound access shall crash the program. Access shall be detected and an exception shall be thrown.
2. Create multiple test cases verifying the capability to create NamedBitBuffer and NamedBitBufferSlice from a NamedBuffer or a NamedBufferSlice.
    2.1 Verify ability to created arbitrary NamedBitBuffer objects.
    2.2 Verify ability to created arbitrary NamedBitBufferSlice objects.
    2.3 Verify ability to created arbitrary NamedBitBufferSlice objects from a NamedBuffer object.
    2.4 Verify ability to created arbitrary NamedBitBufferSlice objects from a NamedBufferSlice object.
    2.5 Verify out of bound access to NamedBitBuffer and NamedBitBufferSlice objects. No out of bound access shall be allowed and no out of bound access shall crash the program. Access shall be detected and an exception shall be thrown.
3. Test NamedBitBuffer and NamedBitBufferSlice in the same way than NamedBuffer and NamedBufferSlice. 
4. Create multiple test cases verifying the deep copy mechanism for NamedObject and its derived classes.
   4.1 Create a tree of NamedObject and its derived classes. Tree shall mix different types of NamedObject and its derived classes.
   4.2 Created tree shall contain NamedBuffer and NamedBufferSlice objects. Some NamedBufferSlice objects shall be based on a NamedBuffer that is their parent. Some shall be based on a NamedBuffer that is not their parent. Some shall be based on a NamedBufferSlice that is their parent. Some shall be based on a NamedBufferSlice that is not their parent.
    4.2.1 NamedBuffer and NamedBufferSlice shall be created with random data and random sizes.
    4.2.2 NamedBufferSlice shall be created with random offsets and random sizes.
   4.3 Verify the deep copy.
    4.3.1 Verify that each pointer of the new tree is different from the original tree.
    4.3.2 Verify that the topology of the new tree is the same than the original tree by a complete traversal. Verification could be helped by smart naming of objects.
    4.3.3 Verify content of NamedBuffer and NamedBufferSlice objects between original and copied tree.
    4.3.4 Verify that a tree can be copied multiple times.
    4.3.5 Verify that a tree can be copied and then modified.
    4.3.6 Verify that the original tree can be deleted without affecting the copied tree. Verify that memory is correctly released.
5. Clean and build the full project.
6. Run all the tests.




## Expected result

A complete deep copy mechanism for NamedObject and its derived classes.
