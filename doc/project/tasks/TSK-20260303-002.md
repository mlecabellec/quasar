## Requirements

- [TSK-20260303-002.1] Implement `void NamedObject::replaceInTree(std::shared_ptr<NamedObject> replacement)` to perform a structural substitution within the object hierarchy.
    - [TSK-20260303-002.1.1] The method must update the parent's reference to `this` with `replacement` and re-parent all children of `this` to `replacement`.
    - [TSK-20260303-002.1.2] Ensure thread safety by following the locking hierarchy and synchronization rules defined in `doc/architecture/CS-0010.md`.
- [TSK-20260303-002.2] Introduce a virtual method for runtime type identification.

## Implementation Plan

1. Analyze code from cmake-projects/named and cmake-projects/coretypes. Analyze classes, methods, dependencies, build system, features, etc.
2. Define a virtual `getType()` method in `NamedObject` and implement it in derived classes to return the class name as a string.
3. Implement `replaceInTree(std::shared_ptr<NamedObject> other)` in `NamedObject`.
    - Update the parent's child reference from `this` to `other`.
    - Update all children's parent reference from `this` to `other`.
    - Handle edge cases like root nodes or leaf nodes.
4. Verify the implementation with unit tests, ensuring that the tree structure remains consistent after replacement and that types are correctly reported.


# Test and validation



1. **Unit Tests for `getType()`**:
    - Create instances of `NamedObject` and its derived classes.
    - Assert that `getType()` returns the expected class name string for each instance.
2. **Unit Tests for `replaceInTree()`**:
    - **Structural Integrity**: Construct a tree, replace a middle node, and verify that the parent now points to the new node and all children of the old node now point to the new node as their parent.
    - **Boundary Conditions**: Test replacement of a root node (no parent) and a leaf node (no children).
    - **Reference Counting**: Ensure that `std::shared_ptr` counts are handled correctly to prevent memory leaks or premature deletion.
3. **Concurrency and Thread-Safety**:
    - Implement a stress test where multiple threads perform `replaceInTree` and tree traversals simultaneously.
    - Verify compliance with `doc/architecture/CS-0010.md` by ensuring proper locking mechanisms (e.g., `std::recursive_mutex` or specific quasar locks) are used during pointer updates.
4. **Regression Testing**:
    - Run existing `quasar::named` test suites to ensure no regressions in existing tree manipulation logic.
