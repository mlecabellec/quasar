# Goal

Implement a comprehensive logic and control engine (LogicEngine) within the Quasar framework, providing support for State Machines, Sequential Function Charts (SFC/Grafcet), and Rule Engines. These components shall be integrated into the `NamedObject` hierarchy and leverage `ActiveEntity` for execution and reflexivity.

# Details

## Context

Industrial automation and complex system control require formal logic modeling to ensure deterministic and maintainable behavior. By providing built-in support for state-driven and rule-based logic, Quasar can represent high-level operational procedures (e.g., startup sequences, safety interlocks, mode management) natively. This task focuses on creating a modular logic framework that reuses the project's core abstractions (`NamedObject`, `ActiveEntity`, `Datacodec`) to provide a unified modeling and execution environment.

## Implementation Plan

1. **Foundations**: Define the abstract interfaces for conditions and actions in `logicengine/include`.
2. **State Machines**: Implement the core HSM logic, ensuring thread-safe state transitions.
3. **SFC/Grafcet Engine**: Develop the step-and-transition execution loop, focusing on deterministic timing.
4. **Rule Engine**: Build the evaluation matching engine using a Rete-like algorithm or a optimized linear scanner for small sets.
5. **Entity Mapping**: Wrap logic components into `ActiveEntity` derivatives and register them with the Quasar service locator.
6. **Scripting Bridge**: Map the high-level logic constructors to the Lua environment.

# Test and validation

- **FSM Correctness**: Verify transition guards and action triggers for complex state charts.
- **SFC Parallelism**: Validate correct synchronization of parallel branches in Grafcet models.
- **Rule Performance**: Benchmark rule evaluation latency for 1000+ rules.
- **Persistence Validation**: Save a complex control logic to JSON, reload it, and verify identical execution behavior.
- **Real-time Integrity**: Use TSan to verify that logic updates occurring in background threads do not corrupt the `NamedObject` hierarchy.

## Expected result

A powerful, industrial-grade logic execution suite that enables Quasar to handle complex, deterministic control tasks using standard modeling formalisms.
