# Goal

Implement a professional-grade, interactive Lua interpreter (REPL) for the Quasar framework, featuring intelligent autocompletion, syntax highlighting, and dynamic plugin loading. This tool, named `quasar-shell`, will serve as a primary interface for real-time debugging, reflexive orchestration, and interactive system exploration.

# Details

## Context

While the Quasar ecosystem provides robust standalone execution (`sre`) and service-based orchestration, there is a clear need for a "Mission Control" style interactive environment. A feature-rich REPL allows engineers to introspect the `NamedObject` hierarchy, trigger `NamedMethod` calls, and hot-load plugins without the overhead of writing and executing full script files. This accelerates the commissioning process and simplifies complex diagnostic sessions.

## Implementation Plan

1. **Library Integration**: Integrate the **ClickHouse fork** of `replxx` into the `third-party` directory using `FetchContent`, ensuring high-performance handling of large inputs.
2. **Plugin Logic Refactoring**: Extract the plugin loading logic from `sre` into a reusable `PluginManager` component within `quasar::scripting`.
3. **Core Shell Implementation**: Develop the REPL loop in `quasar-shell`, integrating the `replxx` interface with the `LuaEngine`'s execution cycle.
4. **Completion Engine**: Develop a C++-to-Lua bridge that extracts available identifiers from the Lua registry and the `NamedObject` root to feed the shell's completion provider.
5. **Interactive Commands**: Register the `ls`, `help`, and `load_plugin` functions in the shell's default Lua context.

# Test and validation

- **Autocompletion Accuracy**: Verify that TAB-completion correctly identifies deeply nested `NamedObject` paths and their reflexive methods.
- **Plugin Persistence**: Verify that a plugin loaded during a shell session correctly registers its types and that those types are immediately usable in subsequent shell commands.
- **Resilience**: Validate that the shell handles Lua runtime errors, infinite loops (via timeout), and invalid syntax without terminating the session.
- **History Verification**: Ensure that command history is correctly saved and reloaded between shell restarts.

## Expected result

A powerful, user-friendly interactive terminal that provides real-time access and control over the entire Quasar ecosystem.
