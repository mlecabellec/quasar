# Goal

Implement advanced web-based visualization and logic editing capabilities within the Quasar Mission Control ecosystem. This includes dynamic SVG-based plant synoptics and real-time visual tracing for State Machines (HSM) and Sequential Function Charts (SFC).

# Details

## Context
Following the completion of the baseline discovery and telemetry APIs, Quasar requires higher-level visual tools to represent complex industrial processes. This task focuses on the extensibility of the `WebUIService` and the React frontend to support declarative visual models that bind directly to the `NamedObject` hierarchy.

## Requirements

### Phase 7: Dynamic SVG Synoptics (Step 7.1)
- [ ] [TSK-20260423-001.1] **Declarative Binding Engine**: Implement a frontend engine that loads an external SVG and binds its element IDs to Quasar tree paths.
- [ ] [TSK-20260423-001.2] **Visual State Mapping**: Support CSS-class toggling and SVG transformations (rotation, scaling, color shifts) based on live WebSocket deltas.
- [ ] [TSK-20260423-001.3] **Interactive Overlays**: Allow clicking on SVG elements to trigger reflexive methods or open detail inspectors.

### Phase 8: Visual Logic Tracing (Step 8.1)
- [ ] [TSK-20260423-001.4] **Live HSM Tracing**: Develop a component that visualizes the `StateMachine` hierarchy and highlights the active state in real-time.
- [ ] [TSK-20260423-001.5] **SFC/Grafcet Flow**: Visualize the active steps and transition status of an `SFC` logic component.
- [ ] [TSK-20260423-001.6] **Visual Log Analysis**: Support "Time Travel" debugging where the UI can replay historical logic transitions from the `DataLogger` backend.

## Implementation Plan (Future)

1. **SVG Integration**: Setup `react-svg` or a custom parser in the `frontend/src/modules/synoptics` directory.
2. **Logic Renderers**: Integrate `reactflow` or a specialized Graphviz-based renderer for hierarchy visualization.
3. **Reflexive Metadata Expansion**: Update the C++ `LogicEngine` to export its structure in a format optimized for graph layout engines (e.g., DOT or custom JSON).

# Test and validation

- **Synoptic Performance**: Verify 60FPS fluid animation for a synoptic with 500+ active SVG elements.
- **Tracing Accuracy**: Ensure the visual highlight precisely matches the C++ `m_state` transitions under 50ms latency.

## Expected result

A high-fidelity visual orchestration layer where system logic and physical infrastructure are represented through intuitive, real-time graphical models.
