# Goal

Implement a ZeroMQ (ZMQ) PUB/SUB plugin for the Quasar scripting environment, enabling Lua scripts to efficiently publish and subscribe to hierarchical trees of `NamedBuffer` objects across the network.

# Details

## Context

For high-performance distributed systems, it is often necessary to transmit large amounts of structured data (e.g., sensor readings, telemetry, or control states) between different nodes. ZeroMQ's PUB/SUB pattern is ideal for this "one-to-many" distribution. By providing a dedicated plugin that can serialize and deserialize `NamedObject` hierarchies—specifically those containing `NamedBuffer` data—Quasar can support low-latency, high-throughput data distribution directly from its scripting layer.

## Implementation Plan

1. **Binary Serialization Bridge**: Implement BSON or a specialized binary serializer in `quasar::named::serialization` that handles `NamedBuffer` efficiently.
2. **ZMQ Wrapper**: Create a thread-safe C++ wrapper for ZMQ PUB/SUB sockets that integrates with the Quasar scripting lifecycle.
3. **Lua Bindings**: Map the ZMQ wrapper to Lua using `sol2`, including the specialized `publishTree` and `receiveTree` methods.
4. **Integration**: Add the plugin to the `cmake-projects/scripting` build system.
5. **Examples**: Create Lua examples demonstrating a data producer publishing a tree of `NamedBuffer` and a consumer subscribing to it.

# Test and validation

- **Serialization Fidelity**: Verify that a tree published by one script is reconstructed identically in another script (same names, types, and buffer content).
- **Throughput Benchmarking**: Measure the maximum number of `NamedBuffer` trees (e.g., 10 buffers of 1KB each) that can be transmitted per second over local loopback.
- **Topic Filtering**: Verify that ZMQ topic subscriptions correctly filter messages at the Lua level.
- **Memory Safety**: Use ASan to verify that receiving malformed ZMQ messages does not cause crashes or memory leaks during reconstruction.
- **Concurrency**: Test multiple publishers and subscribers running in separate threads/processes.

## Expected result

A high-performance ZMQ plugin for the Quasar scripting environment, specifically optimized for distributing `NamedBuffer` hierarchies.
