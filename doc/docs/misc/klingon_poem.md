# A Klingon Poem for Quasar's Victory

Heghlu'meH QaQ jajvam!
(It is a good day to die!)
'ach vaj, jatlhpu' Quasar:
(But instead, Quasar has spoken:)

tlhIngan maH!
(We are Klingons!)

yIqIm! yIqIm!
(Pay attention! Pay attention!)
HoS majQa' je!
(Great power and success!)

The bugs have fallen, the code is clear,
Kahless smiles upon the build this year.
Qapla'!
