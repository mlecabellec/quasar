# Architecture Directory

The architecture folder contains the project's structural documentation, split into categories:
- components (CP-*)
- constraints (CS-*)
- dependencies (DE-*)
- design (DI-*)
- interfaces (IF-*)
- patterns (PA-*)
- quality (QU-*)
- requirements (RE-*)
- tools (TO-*)
- usecases (UC-*)

Each element is defined by a markdown file named with its prefix and a numeric identifier, e.g., `CS-0010.md` for C++ coding standards.
