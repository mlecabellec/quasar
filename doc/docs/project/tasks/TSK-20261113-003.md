### Mandatory Checklist per File (`[CS-0090.1]`–`[CS-0090.9]`)
1. **Universal Entity Coverage (`[CS-0090.1]`)**: Add `@file` + `@brief` + paired `@details` across all namespaces, classes, structs, enums, enumerators, aliases, fields, constants, constructors, destructors, methods, operators, and functions.
2. **Traceability & Compliance Proof (`[CS-0090.2]`)**: Cite originating `@task`/`@feature`/`@requirement`/`@constraint`/`@rule`/`@exposed` IDs and `@compliance` proof explaining *how* constraints are satisfied.
3. **Formal Parameter Contract (`[CS-0090.3]`)**: Document all parameters using `@param[in|out|in,out]` with `Justification:`, `Usage:`, `Consumed:`, and `Prerequisites:`.
4. **Formal Return Value Contract (`[CS-0090.7]`)**: Document non-`void` returns with `@return` (and `@retval` where discrete) covering `Justification:`, `Usage:`, `Consumed:`/`Ownership:`, `Prerequisites:`, `Limitations:`, `Lifecycle:`, `Modification / Deletion:`, `Specific Values:`, and `Error Behavior:`.
5. **Error Categories & Containment (`[CS-0090.8]`)**: Document failure categories (`@throws`, `@error`, `@retval`) and implemented `@containment` strategy plus explicit limitations.
6. **Formal Predicates (`[CS-0090.9]`)**: Express formal `@pre`, `@post`, and `@invariant` contracts aligned with `[CS-0050.1]`.
7. **Safety Hygiene, In-Body & Control Comments (`[CS-0090.4]`, `[CS-0090.5]`, `[CS-0090.6]`, `[CS-0010.44]`)**: Strict 7-bit ASCII, zero commented-out code, zero nested `/* */`, comment cadence `<= 5` code lines inside methods, and `//` operational explanations on every `if`, `else if`, `else`, `switch`, `for`, `while`, `do`, `try`, and `catch`.

### Safety Guardrails
- **Comment-Only Invariant**: Unless fixing an explicit compiler/`cppcheck` bug documented separately, edits under `TSK-20261113-003` modify comments/Doxygen annotations ONLY — no behavioral code alterations or signature deletions (`helpers/detect_deletions.py` must report 0 unintended deletions).
- **Test Integrity**: Existing test assertions/logic must remain strictly intact.
