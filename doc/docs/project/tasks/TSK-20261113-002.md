# [TSK-20261113-002] Close Feature, Structural, Specification, and Compliance Gaps Between `resoem` and `SOEM`

## Goal
Document all protocol features, data structures, architectural mechanisms, and Quasar coding-standard discrepancies identified in `cmake-projects/resoem/` relative to `tmp/SOEM/` (`SOEM 2.0.0`) and formal EtherCAT specifications, and establish an actionable, standards-referenced technical proposal to upgrade `resoem` to full industrial parity.

## Details

### Context
A comprehensive comparative audit was conducted between Quasar's C++23 EtherCAT Master (`cmake-projects/resoem/`) and the external reference `tmp/SOEM/` (`SOEM 2.0.0`). While `resoem` already provides modern C++23 abstractions, RAII AF_PACKET transport, ETG.2100 ENI parsing/generation/comparison (`EniDocument`, `EniConfigurator`, `EniGenerator`, `EniComparator`), Hot Connect (`HotConnectManager`), Cable Redundancy (`RedundancyManager`), and hardware-free simulation (`VirtualEtherCATBus`, `StubRawSocket`, `SimulatedSlave`), several core runtime features from `SOEM 2.0.0`, EtherCAT formal specifications, and Quasar coding standards (`CS-0010`–`CS-0060`) remain incomplete or non-compliant.

### Formal Specifications & Normative References
All proposed master enhancements map directly to the following formal specifications:
1. **ETG.1000.1 – ETG.1000.6** (*EtherCAT Specification — Overview, Physical Layer, Data Link Layer Services/Protocol, Application Layer Services/Protocol*; normative international equivalents **IEC 61158-3-12**, **IEC 61158-4-12**, **IEC 61158-5-12**, **IEC 61158-6-12**, and **IEC 61784-2 CPF 12**).
   - Governs frame structure (`0x88A4`), datagram commands (`APRD`, `FPRD`, `BRD`, `APWR`, `FPWR`, `BWR`, `ARMW`, `FRMW`, `LRD`, `LWR`, `LRW`), SyncManagers (`SM0`–`SM3`), FMMUs, ESM (`INIT`/`PRE_OP`/`BOOT`/`SAFE_OP`/`OP`), SII EEPROM layout, and Mailbox protocols (CoE, FoE, EoE, SoE, AoE, VoE).
   - Governs Distributed Clocks (DC) architecture: propagation delay measurement (`0x0900`–`0x090F`), 64-bit system time reference (`0x0910`), system time offset (`0x0920`), time drift compensation (`ARMW`/`FRMW`), and `SYNC0`/`SYNC1` activation (`0x0980`–`0x09A7`).
2. **ETG.1020** (*EtherCAT Protocol Enhancements*).
   - Governs **Explicit Device Identification** (`AL Control`/`AL Status` identification), **Robust Mailbox Protocol** (retransmission/toggle recovery on mailbox loss via SyncManager state verification), CoE/FoE/EoE protocol clarifications, and mailbox resiliency.
3. **ETG.1500** (*EtherCAT Master Classes*).
   - Defines formal conformance profiles for Master Class A and Master Class B (basic vs. extended mailbox services, CoE Complete Access, SDO Info/OD descriptions, FoE, EoE, SoE, Distributed Clocks, Cable Redundancy, Hot Connect, ENI processing).
4. **ETG.2000** (*EtherCAT Slave Information — ESI Specification*) & **ETG.2010** (*SII Binary Format*).
   - Defines vendor/product identity fields, SyncManager defaults, PDO definitions, and EEPROM categories cached/parsed during bus discovery.
5. **ETG.2100** (*EtherCAT Network Information — ENI Specification*).
   - Defines master/slave initialization commands (`<InitCmd>`), validation masks (`<Validate>`), Hot Connect groups (`<HotConnect>`), cyclic frame layouts (`<Cyclic>`), and SyncUnit process data layouts.
6. **ETG.6010 / CiA 402** (*Drives and Motion Control Profile on EtherCAT*) & **IEC 61800-7** (*Generic Interface and Use of Profiles for Power Drive Systems / SoE — SERCOS over EtherCAT*).
   - Governs CoE PDO assignments (`0x1C12`/`0x1C13`), drive state objects (`0x6040`/`0x6041`), and SoE multi-fragment IDN transfers (`InComplete` flag + remaining fragment counter + element flags).

### Gap Inventory: `cmake-projects/resoem/` vs. `tmp/SOEM/`

#### 1. Transport & Datagram Primitives (`RawSocket`, `IRawSocket`, `EtherCATFrame`, `Enumerator`)
- **Missing Async Pipelined TX/RX Slot Ring (`EC_MAXBUF`)**:
  - *SOEM (`oshw/linux/nicdrv.c/.h`)*: Maintains `EC_MAXBUF` indexed frame buffers, per-index timeout/completion status, and `ecx_waitinframe_red()` handling **out-of-order frame reception** (`A-C-B`) plus **source-MAC verification** (`priMAC` vs `secMAC`) inside the low-level transport.
  - *resoem Gap*: `RawSocket` and `MailboxHandler` execute strictly synchronous single-datagram request/response (`send` then blocking/sleeping `receive`). Pipelined multi-frame process data and concurrent multi-slave mailbox requests are unsupported, and redundancy MAC discrimination is only partially handled in `RedundancyManager`.
- **Missing Adapter Discovery (`ec_find_adapters`)**:
  - *SOEM*: Enumerates Linux network interfaces cleanly for CLI/TUI selection (`ifaddrs` / sysfs).
  - *resoem Gap*: `RawSocket` requires explicit interface names supplied by the caller.
- **Missing Datagram Commands & Combined Cyclic Framing**:
  - *SOEM (`ec_base.c`)*: Implements `LRD`, `LWR`, `FRMW` (DC distribution from reference slave), **`LRWDC`** (combining cyclic `LRW`/`LRD`/`LWR` process data with `FRMW`/`ARMW` DC distribution in one Ethernet frame), **`FPRD_multi`** (batched AL Status read across multiple slaves in one frame), and word helpers (`APRDw`, `FPRDw`, `APWRw`, `FPWRw`).
  - *resoem Gap*: `EtherCATFrame` / `Enumerator` only uses `APRD`, `APWR`, `FPRD`, `FPWR`, `BRD`, `BWR`, `ARMW`, `LRW`. `blockLRW` slaves cannot use separate `LRD` + `LWR` frames, and DC sync is not piggybacked on cyclic IO frames (`LRWDC`).

#### 2. Process Image, IO Mapping & Multi-Group Scheduling (`Enumerator`, `ProcessImage`)
- **Missing `overlappedMode` & `packedMode` Mapping**:
  - *SOEM (`ec_config.c`)*: Supports `ecx_config_overlap_map_group` (overlapping logical Rx/Tx addresses sharing FMMU windows to minimize frame payload) and bit-packed PDO alignment (`packedMode`) across non-byte-aligned slaves.
  - *resoem Gap*: Two-pass contiguous byte-aligned layout only (`Outputs` followed by `Inputs`).
- **Missing Process Image Segmentation (`IOsegment[EC_MAXIOSEGMENTS]`) & `blockLRW` Fallback**:
  - *SOEM*: Automatically splits process images exceeding MTU (`1486` bytes max Ethernet payload minus headers) into multiple scheduled segments/frames and honors `blockLRW` by issuing `LRD` + `LWR`.
  - *resoem Gap*: Assumes a single `LRW` datagram fits in one Ethernet frame (`< 1500` bytes); large networks overflow or truncate.
- **Missing Multi-Group Process Data (`ec_groupt` / `EC_MAXGROUP`)**:
  - *SOEM*: Slaves can belong to independent groups with separate IO maps, expected WKCs, state tracking, and mailbox status polling (`ecx_config_create_mbxstatus_mappings`).
  - *resoem Gap*: Flat single vector of `SlaveInfo` inside `Enumerator` with a single global WKC.
- **Missing Cyclic Mailbox Status FPRD Mapping**:
  - *SOEM*: Embeds compact `FPRD` datagrams on SM1 status (`0x080D`) in the cyclic frame (`mbxstatuslookup`) to avoid polling every idle slave mailbox individually.
  - *resoem Gap*: Polling requires separate `FPRD` transactions inside `MailboxHandler::receive()`.

#### 3. Mailbox Pool, Queue, Robust Mailbox Protocol & Sub-Protocols
- **Missing Centralized Mailbox Pool, TX Queue & Fair Cyclic Handler (`ec_mbxpoolt`, `ec_mbxqueuet`, `ecx_mbxhandler`)**:
  - *SOEM (`ec_main.c`)*: Pre-allocated mailbox slot pool + per-group FIFO/priority TX queue with expiration timers, fair round-robin dispatch during cyclic cycles, automatic **CoE Emergency** capture (`ecx_mbxemergencyerror`), and **Mailbox Error** (`ecx_mbxerror`) reporting without blocking the real-time loop.
  - *resoem Gap*: `MailboxHandler` performs blocking poll loops with `std::this_thread::sleep_for(100us)` per request and lacks Emergency queuing, expiration scheduling, or ETG.1020 **Robust Mailbox Protocol (`mbxrmpstate`)** toggle-bit retry on lost mailbox read/write frames.
- **CoE Gaps (`CoEHandler`)**:
  - *Missing*: Object Entry Description reads (**`ecx_readOE` / `ecx_readOEsingle`** — subindex access rights, data type, bit length, min/max/default, PDO mapping flags); **CoE PDO-over-Mailbox** (`ecx_RxPDO`, `ecx_TxPDO`); full **Complete Access (`CA`)** flag integration on `sdo_read` (`ecx_SDOread(..., CA=true, ...)`) and `read_pdo_mapping_ca` (`ecx_readPDOmapCA`).
- **SoE Gaps (`SoEHandler`, IEC 61800-7)**:
  - *Missing*: Multi-fragment segmented IDN reads/writes (`incomplete` flag and `fragments_left` assembly — explicitly noted as unimplemented in `SoEHandler.cpp:86`), plus `soe_error_to_string()` diagnostics (`ec_soeerror2string`).
- **EoE Gaps (`EoEHandler`, ETG.1000.6)**:
  - *Missing*: IP parameter configuration (`set_ip` / `get_ip` via `EOE_INIT_REQ`/`EOE_GET_IP_PARAM_REQ`), MAC/IP address filtering (`SET_ADDR_FILTER`, `GET_ADDR_FILTER`), timestamp handling, and non-blocking fragment receiver (`read_fragment` + callback hook) usable inside the cyclic mailbox handler. Also `EoEHandler.cpp:56` exits silently on loop bound exhaustion without returning `ECError::Timeout`.
- **FoE Gaps (`FoEHandler`, ETG.1000.6)**:
  - *Missing*: Progress callback hook (`FOEhook` equivalent for firmware flashing progress UIs) and rich FoE error string formatting.

#### 4. Distributed Clocks, Discovery, Recovery & Diagnostics
- **Distributed Clocks (`Enumerator`)**:
  - *SOEM (`ec_dc.c`)*: Measures all 4 port receive timestamps (`DCrtA..D` at `0x0900`–`0x090F`), classifies `consumedports` topology, computes per-slave propagation delay (`0x0928`), establishes a parent/child clock-tree link list (`DCprevious`/`DCnext`), calculates `0x0920` offset relative to the **2000-01-01 DC epoch** (`- 946684800s`), and configures dual pulse generators (`ecx_dcsync0` and **`ecx_dcsync01`**).
  - *resoem Gap*: `sync_clocks()` / `configure_dc()` use simplified propagation/start offsets (`100'000'000 ns`) and lack 4-port branch delay tree solver, 2000-01-01 epoch alignment, and `SYNC1` (`dcsync01`) support.
- **Discovery, SII Cache & Recovery (`Enumerator`)**:
  - *Missing*: SII identity deduplication cache (`esimap` / `ecx_lookup_prev_sii`) to eliminate redundant slow EEPROM reads on identical modules; raw `esidump`, `eeprom2master`/`eeprom2pdi`, AP/FP EEPROM accessors; strict `EC_TEMPNODE` identity validation during `recover_slave()` prior to re-assigning station address; per-slave `PO2SOconfig` hook inside `reconfigure_slave()`.
- **Diagnostics & Thread-Safe Error Ring (`Diagnostics`)**:
  - *Missing*: Bounded circular error queue (`ErrorRing` equivalent to `ecx_pusherror`/`ecx_poperror`/`ecx_iserror`) with timestamp, slave index, error domain (`SDO`, `MBX`, `FoE`, `SoE`, `Emergency`, `AL`), `mbx_error_to_string()`, and `soe_error_to_string()`.
- **Quasar Tree Integration (`EthercatSlave`, `EthercatMasterService`, `SimulatedSlave`)**:
  - `EthercatSlave` only binds basic address/identity metadata rather than reflecting full live `SlaveInfo`, PDOs, CoE OD dictionaries, and port counters as child `NamedObject` nodes (`TODO.md` Phase 4).
  - `SimulatedSlave` emulates ESC/SM/ESM/EEPROM registers but lacks simulated CoE/FoE/EoE mailbox responders unless bridged with `resoes`.

#### 5. Quasar Standards Compliance Gaps Inside `resoem`
Direct execution of `helpers/compliance_suite.py`, `helpers/check_metrics.py`, and `helpers/check_annotations.py` on `cmake-projects/resoem/` revealed:
- `[CS-0060.6]` C `union`s in `EtherCATTypes.hpp` (`foe::Header`) and `SoEHandler.hpp` (`SoEHeader`).
- `[CS-0010.35]` `EniDocument.cpp::parse_slave_section` (`356` lines > `200` line limit).
- `[CS-0010.46]` Missing `std::timed_mutex` guards on shared mutable members in `Enumerator`, `MailboxHandler`, `CoEHandler`, `FoEHandler`, `EoEHandler`, `SoEHandler`.
- `[CS-0020.69]` `volatile sig_atomic_t` signal flags in `samples/testmaster100.cpp`, `eoe_test.cpp`, `simple_ng.cpp` (should use `std::atomic<bool>`).
- `[CS-0050.2]`, `[CS-0040.6]`, `[CS-0010.44]`, `[CS-0010.45]`: Implicit boolean checks (`(flag)`), lowercase `const` names, long uncommented blocks, and missing Doxygen annotations across `include/`, `src/`, `samples/`, `tools/`.
- Note: Existing `cmake-projects/resoem/test/test_*.cpp` files also contain legacy violations, which MUST NOT be modified until explicitly approved.

### Technical Proposal & Study

#### Design Principles
Rather than porting `SOEM`'s C structs verbatim (which would reintroduce `auto`/`union`/raw-pointer/global-state violations), each gap should be closed in native Quasar C++23 style:
1. **Zero-Regression Modular Evolution**: Preserve all existing public `resoem` signatures (`Enumerator`, `CoEHandler`, etc.) so all existing ENI, Hot Connect, Redundancy, and Virtual Bus suites remain green.
2. **Data-Oriented Pipelined Transport**: Upgrade `IRawSocket` / `RawSocket` with an optional **Indexed Transaction Ring (`FrameRing<MAX_INFLIGHT_FRAMES>`)** keyed by 8-bit EtherCAT datagram `idx` (`0`..`255`) using `std::array` and `std::timed_mutex` + `std::condition_variable_any` so multiple datagrams (e.g., `LRW` + batched `FPRD_multi` + mailbox `FPRD`/`FPWR`) can fly concurrently and handle out-of-order arrivals and dual-NIC `priMAC`/`secMAC` deduplication cleanly.
3. **Unified Cyclic Scheduler Engine**: Introduce a `CyclicScheduler` class (owned by `Enumerator` or `EthercatMasterService`) implementing the ETG.1000 real-time cycle:
   - Step 1: Transmit segmented `IOGroup` process-data frames (`LRW` / `LRD`+`LWR` / `LRWDC`) + embedded cyclic `FPRD` SM1 mailbox-status checks.
   - Step 2: Receive indexed frames, merge redundancy primary/secondary buffers, extract WKC + DC system time (`0x0910`), and update `ProcessImage` under `std::timed_mutex`.
   - Step 3: Drive a non-blocking **Mailbox Engine** (`MailboxPool` + per-group `MailboxQueue` + `RobustMailboxProtocol` toggle-state machine + auto `Emergency` decoder pushing into a bounded `ErrorRing`).
4. **Protocol Completions**:
   - **CoE**: Add `read_object_entry()` (`0x05`/`0x06`), `sdo_read(..., bool complete_access)`, `write_pdo_mailbox()`/`read_pdo_mailbox()`.
   - **SoE**: Implement `incomplete` + `fragments_left` assembly buffer with `MAX_SOE_FRAGMENTS` safety cap (`CS-0010.37`).
   - **EoE**: Add `EoEIpConfig` (`set_ip`/`get_ip`), filter configuration, and `poll_fragment()` callback dispatch.
   - **DC**: Implement exact 4-port parent/child propagation solver (`DCrtA..D`), epoch-2000 `0x0920` offset, and `configure_dc_sync01()`.
5. **Dual-Stack End-to-End Testbed (`resoem` <-> `resoes`)**:
   - Connect `resoes::MemoryEscHardware` directly into `resoem::VirtualEtherCATBus` to validate every new ETG feature (SDO CA, OD Info, segmented SoE, EoE IP setup, FoE boot flash, DC `SYNC01`, Robust Mailbox retries, and Hot Connect recovery) deterministically in CI with ASan/TSan and zero physical hardware.

#### Proposed Phased Implementation Roadmap
- **Phase 0 (Current)**: Fix all non-test CS-0010..CS-0060 compliance violations in `cmake-projects/resoem/` (`include/`, `src/`, `samples/`, `tools/`) and verify all existing tests + new stress/concurrency tests pass.
- **Phase 1**: Datagram primitives (`LRD`, `LWR`, `FRMW`, `LRWDC`, `FPRD_multi`, adapter discovery) and indexed async `FrameRing` in `RawSocket`/`StubRawSocket`.
- **Phase 2**: IO segmentation (`> 1486 B`), `blockLRW`, `overlappedMode`, `packedMode`, and multi-group `ProcessGroup` support.
- **Phase 3**: Centralized `MailboxPool`, `MailboxQueue`, ETG.1020 Robust Mailbox Protocol, `CoE` Emergency auto-handler, and `ErrorRing` in `Diagnostics`.
- **Phase 4**: Complete CoE (`read_object_entry`, `CA` SDO read, CoE PDO-over-MBX), segmented SoE, EoE IP/filter/async fragments, FoE progress hooks, and string diagnostics.
- **Phase 5**: Full 4-port Distributed Clocks propagation solver, epoch-2000 offset, and `dcsync01`.
- **Phase 6**: SII identity cache (`esimap`), `EC_TEMPNODE` identity recovery, `PO2SOconfig` hooks, `EthercatSlave` full `NamedObject` mirroring, and `resoes` loop integration tests.

## Test and validation
- Regression suite: all existing `resoem` unit tests (`test_soe_framing`, `test_dc_calc`, `test_diagnostics`, `test_topology`, `test_eni_parser`, `test_virtual_bus`, `test_eni_configurator`, `test_redundancy_loop`, `test_hot_connect`, `test_eni_generator_comparator`) plus new concurrency/stress tests.
