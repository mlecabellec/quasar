# Goal

Implement a comprehensive calibration and value transformation framework (Calibration) within the Quasar ecosystem, enabling high-fidelity conversion between raw system data and engineering units.

# Details

## Context

In industrial and scientific systems, raw data acquired from hardware (e.g., ADC counts, bit-fields) must often be transformed into meaningful physical quantities (e.g., Temperature in Celsius, Pressure in Bar) for analysis and visualization. Conversely, control commands in engineering units must be de-calibrated back to raw values for hardware consumption. This task focuses on providing a modular, extensible C++ framework for defining and applying these transformations, reusing `NamedObject` for configuration and `Variant` for data handling.

## Implementation Plan

1. **Foundational Interfaces**: Define `ICalibration` and its basic exception types in `calibration/include`.
2. **Mathematical Codecs**: Implement Linear, Polynomial, and Point-Pair logic, ensuring high-precision floating-point math.
3. **Discrete Mappers**: Implement StatesCode and Enum logic using efficient lookup structures (e.g., `std::map`).
4. **Named Integration**: Wrap the mathematical logic into `NamedObject` subclasses to allow hierarchical configuration.
5. **Manager Implementation**: Create the `CalibrationManager` for lifecycle and discovery.
6. **Scripting & External Hook**: Map the API to Lua and provide hooks for `datacodec`.

# Test and validation

- **Precision Validation**: Verify polynomial transformations against known theoretical values with at least 15 digits of precision.
- **Interpolation Accuracy**: Test point-pair calibrations with various slope changes and verify linear interpolation correctness.
- **Bidirectional Symmetry**: For invertible calibrations (like Linear), verify that `engToRaw(rawToEng(x)) \approx x`.
- **Enum Robustness**: Verify behavior when mapping undefined states (e.g., default values or error states).
- **Scale Testing**: Benchmark the transformation rate for large arrays of data; ensure negligible overhead compared to raw data access.
- **Serialization Integrity**: Save a complex calibration chain to YAML, reload it, and verify identical transformation results.

## Expected result

A robust, type-safe, and highly performant calibration library that provides a unified way to handle physical quantity transformations across the entire Quasar project.
