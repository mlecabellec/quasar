# Goal

Ensure that `quasar::coretypes::Integer<T>` provides full polymorphic implementations and method variations for all base integer types, enabling high-precision, type-safe arithmetic and bitwise operations across different integer widths without intermediate floating-point conversion.

# Details

## Context

The core type system must support seamless and precise interoperability between different integer representations (`int8_t`, `int16_t`, `int32_t`, `int64_t`, `uint8_t`, `uint16_t`, `uint32_t`, `uint64_t`, `size_t`, `ptrdiff_t`). Relying on intermediate `double` or `long` casts is insufficient for large 64-bit integers and violates the principles of a robust, type-checked core architecture.

## Requirements

- [x] [TSK-20260308-001.1] **Full Polymorphic Dispatch**: Refactor `quasar::coretypes::Integer<T>` to implement polymorphic arithmetic (`add`, `subtract`, `multiply`, `divide`) and bitwise operations (`bitwiseAnd`, `bitwiseOr`, `bitwiseXor`, `bitwiseNot`, `bitwiseLeftShift`, `bitwiseRightShift`) for all combinations of base integer types.
- [x] [TSK-20260308-001.2] **Precision Safety**: Ensure that operations between any two `Integer` instances (e.g., `Integer<int32>` and `Integer<uint64>`) are performed with full precision, avoiding any intermediate casting to `double` or other lossy types.
- [x] [TSK-20260308-001.3] **Method Variations**: Provide explicit method overrides or specializations for each base integer type (`int8_t`, `int16_t`, `int32_t`, `int64_t`, `uint8_t`, `uint16_t`, `uint32_t`, `uint64_t`, `size_t`, `ptrdiff_t`) to support efficient discovery and usage in generic/templatized contexts.
- [x] [TSK-20260308-001.4] **Safe Operations Support**: Extend the `safe*` variants of arithmetic methods to follow the same polymorphic, full-precision rules.
- [x] [TSK-20260308-001.5] **Exhaustive Testing Coverage**: All implemented polymorphic methods must be covered by a comprehensive test suite. This includes testing all $10 \times 10$ combinations of base integer types for every arithmetic and bitwise operation, covering trivial cases (zero, one) and edge cases (max, min, potential wrap-around).

## Implementation Plan

1. **Architecture Redesign**:
    - Implement a Double Dispatch or Visitor Pattern in the `Number` base class and `Integer<T>` template class to allow type-safe resolution of operations involving two different `Integer` instantiations.
2. **Method Implementation**:
    - For each base integer type, implement the specific logic for interaction with every other base integer type.
    - Ensure correct promotion and overflow handling according to C++ standards and project safety rules.
3. **Template Instantiation**:
    - Provide explicit template instantiations for `Integer<T>` for all required base types to ensure binary symbol availability and consistency.
4. **Comprehensive Test Suite**:
    - Develop a templatized test framework that programmatically generates test cases for all type combinations.
    - Implement coverage for all arithmetic, bitwise, and comparison methods.

# Test and validation

- **Matrix-Based Correctness**: Automated execution of $(10 \times 10)$ type combinations for all 15+ polymorphic methods (arithmetic, bitwise, comparison).
- **Trivial Cases**: Validate 0, 1, and -1 (for signed) across all type boundaries.
- **Edge Case Validation**: Force operations near `numeric_limits<T>::max()` and `min()` to verify correct behavior (e.g., wrap-around for unsigned, exception/UB handling for signed).
- **Precision Validation**: Verify that 64-bit integer operations do not exhibit the precision loss associated with `double` conversion (e.g., adding `1` to `2^53`).
- **Bitwise Consistency**: Validate that bitwise operations work correctly across different underlying storage widths.
- **Type Safety**: Ensure that the compiler correctly resolves specialized method variations for all 10 base integer types.
- **Range and overflow safety**: Ensure that safe arithmetic operations are correctly implemented and tested.

## Expected result

A high-performance, precision-safe core integer library that supports full polymorphic interoperability between all standard integer types.
