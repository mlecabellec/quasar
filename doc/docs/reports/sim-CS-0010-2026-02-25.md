# C++ Level and Standards Conformance Report

**Project:** sim
**Constraint:** CS-0010 – C++ level and standards
**Date:** 2026-02-25

## 1. Constraint Overview

| Rule | Key Requirement |
|------|----------------|
| CS‑0010.1 | Use C++23 or higher; interfaces compatible with C++23 |
| CS‑0010.2 | Move semantics for by‑value parameter passing |
| CS‑0010.3 | Const references for by‑reference parameter passing |
| CS‑0010.4 | Move semantics for returned objects |
| CS‑0010.5 | Thread‑safe containers for shared objects |
| CS‑0010.6 | `shared_ptr`/`weak_ptr` for shared ownership |
| CS‑0010.7 | `unique_ptr` for non‑shared fields |
| CS‑0010.8 | Avoid `unique_ptr` in single‑scope usage |
| CS‑0010.9 | Zero/one/three rule for constructor params |
| CS‑0010.10‑23 | Disallow raw `new/delete`, `malloc/free` etc.; enforce RAII for mutexes, files, sockets, memory‑mappings |
| CS‑0010.27‑28 | Avoid indefinite waits/sleeps; use time‑outs |
| CS‑0010.29‑31 | Avoid global variables/functions/constants |
| CS‑0010.32 | Declarations contained in a namespace |
| CS‑0010.33‑34 | Explicit and initialized declarations |
| CS‑0010.35 | `auto` type forbidden |
| CS‑0010.36‑38 | Function/body and class/body size limits, `goto` forbidden |
| CS‑0010.39‑40 | Infinite loops/recursion must have hard limits |
| CS‑0010.41‑45 | Replace literals → constants → enums → templates → concepts → traits |
| CS‑0010.46‑47 | Comments required; Doxygen documentation for all public API |

> *Full list in `doc/architecture/CS-0010.md`*

## 4. Verification Summary
- **Build**: Add `set(CMAKE_CXX_STANDARD 23)` to `CMakeLists.txt`.
- **Static Analysis**: Configure `cppcheck` with the CS‑0010 rule set; run as part of CI.
- **Unit Tests**: Existing test demonstrates basic functioning; add tests for exception safety, move semantics, and thread‑safety.
- **Documentation**: Add Doxygen comments to all public classes, methods, and functions; generate docs.
