# Feature 0250

## Title

Provide a comprehensive calibration and value transformation framework.

## Description

The system shall provide a framework for defining and applying mathematical and logical transformations (calibrations) to system data, enabling high-fidelity conversion between raw system data and engineering units.

The following capabilities and features shall be provided:

- [FE-0250.1] **Core Calibration Module**
    - [FE-0250.1.1] Create sub-project `cmake-projects/calibration`.
    - [FE-0250.1.2] Define abstract `ICalibration` interface with `rawToEng` and `engToRaw` methods.
- [FE-0250.2] **Standard Calibration Types**
    - [FE-0250.2.1] Provide Identity, Linear, Polynomial, and Point-Pair (Look-up Table) calibrations.
    - [FE-0250.2.2] Provide Enum/States Code mapping (Discrete values to Strings).
    - [FE-0250.2.3] Support numeric-to-string formatting with precision and units.
- [FE-0250.3] **Named Calibration Registry**
    - [FE-0250.3.1] Implement calibrations as `NamedObject` derivatives (`NamedLinearCalibration`, etc.).
    - [FE-0250.3.2] Provide a `CalibrationManager` for discovery and retrieval of calibrations.
- [FE-0250.4] **Composite & Conditional Transformations**
    - [FE-0250.4.1] Support chaining multiple calibrations (Composite pattern).
    - [FE-0250.4.2] Implement conditional calibrations where logic changes based on related object values.
- [FE-0250.5] **Integration & Scripting**
    - [FE-0250.5.1] Provide full Lua/Python bindings.
    - [FE-0250.5.2] Integrate with `datacodec` for seamless conversion during binary encoding/decoding.
- [FE-0250.6] **Serialization**
    - [FE-0250.6.1] Ensure all calibration definitions are compatible with JSON/XML/YAML serialization.

Project shall be located in `cmake-projects/calibration`.
