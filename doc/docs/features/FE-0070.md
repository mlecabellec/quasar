# Feature 0070

## Title

SMP Standard - Simulation Environment Services

## Description

This feature covers the simulation environment services and related interfaces from ECSS-E-ST-40-07C Rev.1 (Section 5.3).

## Requirements

The following capabilities and features shall be provided:

- [FE-0070.1] Logger (ILogger interface)
    - [FE-0070.1.1] (ECSS-E-ST-40-07_1630189) The Simulation Environment shall provide an ILogger component.
    - [FE-0070.1.2] (ECSS-E-ST-40-07_1630190) The ILogger shall maintain a mapping of Log Message Kinds.
    - [FE-0070.1.3] (ECSS-E-ST-40-07_1630191) The ILogger QueryLogMessageKind method shall translate names to IDs.
    - [FE-0070.1.4] (ECSS-E-ST-40-07_1630192) Table 5-7 defines default Log Message Kinds: Debug, Error, Warning, Event, Information.
    - [FE-0070.1.5] (ECSS-E-ST-40-07_1630193) The LogMessageKind mapping shall be persisted.
    - [FE-0070.1.6] (ECSS-E-ST-40-07_1630194) The ILogger Log method shall log a message.

- [FE-0070.2] Time Keeper (ITimeKeeper)
    - [FE-0070.2.1] (ECSS-E-ST-40-07_1630195) The simulation environment shall provide an ITimeKeeper component.
    - [FE-0070.2.2] (ECSS-E-ST-40-07_1630196) The ITimeKeeper SetEpochTime method shall set the Epoch Time.
    - [FE-0070.2.3] (ECSS-E-ST-40-07_1630197) The ITimeKeeper SetMissionStartTime method shall set the Mission start time.
    - [FE-0070.2.4] (ECSS-E-ST-40-07_1630198) The ITimeKeeper SetMissionTime method shall set the Mission time.
    - [FE-0070.2.5] (ECSS-E-ST-40-07_1630199) The ITimeKeeper SetSimulationTime method shall advance Simulation time.
    - [FE-0070.2.6] (ECSS-E-ST-40-07_1630200) ITimeKeeper GetSimulationTime shall return Simulation time.
    - [FE-0070.2.7] (ECSS-E-ST-40-07_1630201) ITimeKeeper GetEpochTime shall return Epoch time.
    - [FE-0070.2.8] (ECSS-E-ST-40-07_1630202) ITimeKeeper GetMissionTime shall return Mission time.
    - [FE-0070.2.9] (ECSS-E-ST-40-07_1630203) ITimeKeeper GetMissionStartTime shall return Mission Start Time.
    - [FE-0070.2.10] (ECSS-E-ST-40-07_1630204) ITimeKeeper GetZuluTime shall return Zulu time.

- [FE-0070.3] Scheduler (IScheduler)
    - [FE-0070.3.1] (ECSS-E-ST-40-07_1630205) The simulation environment shall provide an IScheduler component.
    - [FE-0070.3.2] (ECSS-E-ST-40-07_1630206) The Scheduler shall support Events with repeat count.
    - [FE-0070.3.3] (ECSS-E-ST-40-07_1630207) The Scheduler shall support cycle time for cyclic Events.
    - [FE-0070.3.4] (ECSS-E-ST-40-07_1630208) Events shall be executed first-posted, first-executed.
    - [FE-0070.3.5] (ECSS-E-ST-40-07_1630209) IScheduler AddSimulationTimeEvent shall add an Event.
    - [FE-0070.3.6] (ECSS-E-ST-40-07_1630210) IScheduler AddMissionTimeEvent shall add an Event.
    - [FE-0070.3.7] (ECSS-E-ST-40-07_1630211) IScheduler AddEpochTimeEvent shall add an Event.
    - [FE-0070.3.8] (ECSS-E-ST-40-07_1630212) IScheduler AddZuluTimeEvent shall add an Event.
    - [FE-0070.3.9] (ECSS-E-ST-40-07_1630213) IScheduler AddImmediateEvent shall add an immediate Event.
    - [FE-0070.3.10] (ECSS-E-ST-40-07_1630214) EventId shall be unique throughout simulation.
    - [FE-0070.3.11] (ECSS-E-ST-40-07_1630215) IScheduler RemoveEvent shall remove an Event.
    - [FE-0070.3.12] (ECSS-E-ST-40-07_1630216) IScheduler SetEventSimulationTime shall update Event time.
    - [FE-0070.3.13] (ECSS-E-ST-40-07_1630217) IScheduler SetEventMissionTime shall update Event time.
    - [FE-0070.3.14] (ECSS-E-ST-40-07_1630218) IScheduler SetEventEpochTime shall update Event time.
    - [FE-0070.3.15] (ECSS-E-ST-40-07_1630219) IScheduler SetEventZuluTime shall update Event time.
    - [FE-0070.3.16] (ECSS-E-ST-40-07_1630220) IScheduler SetEventCycleTime shall update Event cycle.
    - [FE-0070.3.17] (ECSS-E-ST-40-07_1630221) IScheduler SetEventRepeat shall update Event repeat count.
    - [FE-0070.3.18] (ECSS-E-ST-40-07_1630222) IScheduler GetCurrentEventId shall return current EventId.
    - [FE-0070.3.19] (ECSS-E-ST-40-07_1630223) IScheduler GetNextScheduledEventTime shall return next Event time.
    - [FE-0070.3.20] (ECSS-E-ST-40-07_1630224) Scheduler state shall be persisted.
    - [FE-0070.3.21] (ECSS-E-ST-40-07_1630225) EpochTimeChange event updates scheduled epoch events.
    - [FE-0070.3.22] (ECSS-E-ST-40-07_1630226) MissionTimeChange event updates scheduled mission events.
    - [FE-0070.3.23] (ECSS-E-ST-40-07_1630227) In Standby, only Zulu time events are executed.
    - [FE-0070.3.24] (ECSS-E-ST-40-07_1630228) SetEventSimulationTime for current event overrides cycle time for next execution.
    - [FE-0070.3.25] (ECSS-E-ST-40-07_1630229) Error if SetEventSimulationTime called on event with zero repeats left.
    - [FE-0070.3.26] (ECSS-E-ST-40-07_1630230) -1 is valid for event time/cycle (implies not active).
    - [FE-0070.3.27] (ECSS-E-ST-40-07_1630231) SetEventRepeat decrements repeat count for current event.
    - [FE-0070.3.28] (ECSS-E-ST-40-07_1630232) IScheduler IsEventScheduled checks if event is in scheduler.
    - [FE-0070.3.29] (ECSS-E-ST-40-07_1630233) IScheduler AddRelativeZuluTimeEvent adds relative Zulu event.

- [FE-0070.4] Event Manager (IEventManager)
    - [FE-0070.4.1] (ECSS-E-ST-40-07_1630234) The simulation environment shall provide an IEventManager component.
    - [FE-0070.4.2] (ECSS-E-ST-40-07_1630235) IEventManager QueryEventId shall return Event identifier.
    - [FE-0070.4.3] (ECSS-E-ST-40-07_1630236) Event Manager shall maintain a list of pairs of event IDs and entry points.
    - [FE-0070.4.4] (ECSS-E-ST-40-07_1630237) Event Manager list is empty at creation.
    - [FE-0070.4.5] (ECSS-E-ST-40-07_1630238) IEventManager Subscribe shall subscribe an entry point to an event.
    - [FE-0070.4.6] (ECSS-E-ST-40-07_1630239) IEventManager Unsubscribe shall unsubscribe an entry point.
    - [FE-0070.4.7] (ECSS-E-ST-40-07_1630240) IEventManager Emit shall emit a global event.
    - [FE-0070.4.8] (ECSS-E-ST-40-07_1630241) Predefined global events shall be emitted as per Table 5-8.
    - [FE-0070.4.9] (ECSS-E-ST-40-07_1630242) Predefined global events shall set synchronous flag as per Table 5-8.
    - [FE-0070.4.10] (ECSS-E-ST-40-07_1630243) State transition event shall not trigger another transition.
    - [FE-0070.4.11] (ECSS-E-ST-40-07_1630244) Subscription changes during Emit apply to next Emit.
    - [FE-0070.4.12] (ECSS-E-ST-40-07_1630245) Table 5-8 defines conditions for emitting predefined global events.

- [FE-0070.5] Resolver (IResolver)
    - [FE-0070.5.1] (ECSS-E-ST-40-07_1630246) The simulation environment shall provide an IResolver component.
    - [FE-0070.5.2] (ECSS-E-ST-40-07_1630247) IResolver ResolveAbsolute shall resolve an absolute path.
    - [FE-0070.5.3] (ECSS-E-ST-40-07_1630248) IResolver ResolveRelative shall resolve a relative path.

- [FE-0070.6] Link Registry (ILinkRegistry)
    - [FE-0070.6.1] (ECSS-E-ST-40-07_1630249) The simulation environment shall provide an ILinkRegistry service.
    - [FE-0070.6.2] (ECSS-E-ST-40-07_1630250) ILinkRegistry AddLink shall increment link count.
    - [FE-0070.6.3] (ECSS-E-ST-40-07_1630251) ILinkRegistry GetLinkCount shall return link count.
    - [FE-0070.6.4] (ECSS-E-ST-40-07_1630252) ILinkRegistry RemoveLink shall decrement link count.
    - [FE-0070.6.5] (ECSS-E-ST-40-07_1630253) ILinkRegistry GetLinkSources shall return source components.
    - [FE-0070.6.6] (ECSS-E-ST-40-07_1630254) ILinkRegistry CanRemove shall check if removal is possible.
    - [FE-0070.6.7] (ECSS-E-ST-40-07_1630255) ILinkRegistry RemoveLinks shall remove links.

- [FE-0070.7] Simulator (ISimulator)

    - [FE-0070.7.2] (ECSS-E-ST-40-07_1630257) Simulator shall have "Models" and "Services" containers.
    - [FE-0070.7.3] (ECSS-E-ST-40-07_1630258) Setup sequence: Publish/Configure -> Connect -> Initialise.
    - [FE-0070.7.4] (ECSS-E-ST-40-07_1630259) ISimulator Publish shall call Publish on components.
    - [FE-0070.7.5] (ECSS-E-ST-40-07_1630260) ISimulator Configure shall call Configure on components.
    - [FE-0070.7.6] (ECSS-E-ST-40-07_1630261) ISimulator Connect shall call Connect on components.
    - [FE-0070.7.7] (ECSS-E-ST-40-07_1630262) ISimulator Initialise shall call initialisation entry points.

    - [FE-0070.7.15] (ECSS-E-ST-40-07_1630270) ISimulator GetState shall return simulator state.
    - [FE-0070.7.16] (ECSS-E-ST-40-07_1630271) ISimulator AddInitEntryPoint shall add init entry point.
    - [FE-0070.7.17] (ECSS-E-ST-40-07_1630272) ISimulator AddModel shall add a model.
    - [FE-0070.7.18] (ECSS-E-ST-40-07_1630273) ISimulator AddService shall add a service.
    - [FE-0070.7.19] (ECSS-E-ST-40-07_1630274) ISimulator GetService shall return a service.
    - [FE-0070.7.20] (ECSS-E-ST-40-07_1630275) ISimulator GetLogger shall return the Logger service.
    - [FE-0070.7.21] (ECSS-E-ST-40-07_1630276) ISimulator GetTimeKeeper shall return the TimeKeeper service.
    - [FE-0070.7.22] (ECSS-E-ST-40-07_1630277) ISimulator GetScheduler shall return the Scheduler service.
    - [FE-0070.7.23] (ECSS-E-ST-40-07_1630278) ISimulator GetEventManager shall return the EventManager service.
    - [FE-0070.7.24] (ECSS-E-ST-40-07_1630279) ISimulator GetResolver shall return the Resolver service.

    - [FE-0070.7.26] (ECSS-E-ST-40-07_1630281) ISimulator RegisterFactory shall register a factory.
    - [FE-0070.7.27] (ECSS-E-ST-40-07_1630282) ISimulator CreateInstance shall create a component instance.
