# Feature 0120

## Title

Add support for lua scripting.

## Description

Providing a lightweight, embedded Lua scripting mechanism allows managing dynamically loadable system behavior without requiring binary recompilation, significantly accelerating the iteration cycle. Integration must prioritize high precision for industrial data (64-bit integers) and real-time responsiveness.

The following capabilities and features shall be provided:

- [FE-0120.1] Support for Lua 5.4.
- [FE-0120.2] Integrate `sol2` as the primary C++ wrapper for Lua.
- [FE-0120.3] Initialize a new CMake project `cmake-projects/scripting`.
- [FE-0120.4] Full CoreType Binding: Expose Variant, Timestamp, Status, and specifically Integer<T> (8-64 bit, signed/unsigned) to Lua with operator parity.
- [FE-0120.5] Named Object Bridge.
- [FE-0120.6] Modular Binding: Define `ILuaModule`.
- [FE-0120.7] Component Lifecycle: Implement `ScriptComponent`.
- [FE-0120.8] Robust ScriptManager.
- [FE-0120.9] Service Discovery.
- [FE-0120.10] Real-time GC Management.
- [FE-0120.11] Interactive REPL.
- [FE-0120.12] One-Shot Execution.
- [FE-0120.13] Sync/Async Execution.
- [FE-0120.14] Persistent Lua Services.
- [FE-0120.15] Thread Pool Integration.
- [FE-0120.16] Advanced Object Lifecycle.
- [FE-0120.17] Extensible C++ Classes.

## Expected result

A robust Lua environment supporting real-time industrial tasks.
