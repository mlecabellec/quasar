# Feature 0130

## Title

Provide a generic interface and implementation for active components (ActiveEntity) with reflexivity and observer/producer capabilities.

## Description

The system requires a standardized way to represent operational entities—such as hardware device abstractions, protocol interfaces, and background services—within the `named` object hierarchy.

The following capabilities and features shall be provided:

- [FE-0130.1] Lifecycle Management
    - [FE-0130.1.1] Define an abstract base class `ActiveEntity` inheriting from `NamedObject` to represent active components.
    - [FE-0130.1.2] Provide virtual lifecycle hooks (`initialize`, `start`, `stop`, `reset`) for controlling component states.
    - [FE-0130.1.3] Maintain an atomic internal state machine representing the lifecycle state (`Uninitialized`, `Ready`, `Running`, `Error`).

- [FE-0130.2] Observer and Producer Pattern
    - [FE-0130.2.1] Define an `IObserver` interface with a notification mechanism.
    - [FE-0130.2.2] Provide a thread-safe subscription engine inside `ActiveEntity` allowing observers to register via weak references.
    - [FE-0130.2.3] Provide a dispatch mechanism for the producer to broadcast event payloads to all active subscribers.

- [FE-0130.3] Field Reflexivity
    - [FE-0130.3.1] Implement a mechanism to register and query member variables (fields) that are themselves `NamedObject` derivatives.
    - [FE-0130.3.2] Provide an API to retrieve fields dynamically by name at runtime.

- [FE-0130.4] Method Reflexivity
    - [FE-0130.4.1] Define a dynamic method dispatch system allowing the entity to register executable commands via an `ICommand` interface.
    - [FE-0130.4.2] Support binding native C++ methods and `std::function` seamlessly to the reflexivity engine.
    - [FE-0130.4.3] Allow executing these bound methods dynamically by name, passing a `NamedObject` as an argument and returning a `NamedObject`.

Classes shall be associated with "quasar::named" namespace.

Project shall be located in cmake-projects/named.

## Expected result

A versatile, reflexive C++ base framework that standardizes how high-level logical components, services, and hardware abstractions are structured, interacted with, and monitored within the Quasar ecosystem.
