# Feature 0110

## Title

Improve and expand the core type system in `quasar::named` and `quasar::coretypes` to support advanced modeling and scripting.

## Description

Structural improvements to `quasar::named` and `quasar::coretypes` are necessary precursors to robust Python and Lua bindings. A richer set of core types (containers, variants, temporal) enables a dynamic, type-safe object hierarchy suitable for industrial infrastructure management.

The following capabilities and features shall be provided:

- [FE-0110.1] Structural Improvements
    - [FE-0110.1.1] Tree Substitution: Implement `void NamedObject::replaceInTree(std::shared_ptr<NamedObject> replacement)` for structural substitution.
    - [FE-0110.1.2] Runtime Type Identification (RTTI)
- [FE-0110.2] Managed Containers & Variants
    - [FE-0110.2.1] Named Collections: Implement `NamedArray<T>`, `NamedMap<K, V>`, and `NamedSet<T>`.
    - [FE-0110.2.2] Named Variants: Implement `NamedVariant` and collection variants.
- [FE-0110.3] Advanced Core Types
    - [FE-0110.3.1] Temporal Types: Implement `Date`, `Timestamp`, and `Duration`.
    - [FE-0110.3.2] Units & Quantities: Implement a lightweight unit system (SI-based).
- [FE-0110.4] Serialization
    - [FE-0110.4.1] Unified Serialization: Ensure all new types are compatible with the `quasar::named::Serialization` framework.

## Expected result

A robust, thread-safe, and highly expressive core type system that enables complex system modeling and seamless scripting integration.
