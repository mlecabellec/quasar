# Feature 0190

## Title

Provide a ZeroMQ (ZMQ) PUB/SUB plugin for high-performance tree distribution.

## Description

The system shall provide a ZeroMQ-based plugin that enables efficient distribution of `NamedObject` hierarchies, specifically `NamedBuffer` trees, across the network using the PUB/SUB pattern.

The following capabilities and features shall be provided:

- [FE-0190.1] **ZMQ Integration**
    - [FE-0190.1.1] Expose ZMQ context and PUB/SUB socket types to Lua.
    - [FE-0190.1.2] Support standard ZMQ operations: `bind`, `connect`, `subscribe`, `unsubscribe`, `send`, `receive`.
- [FE-0190.2] **Tree Serialization**
    - [FE-0190.2.1] Implement an efficient binary serialization format for `NamedObject` hierarchies.
    - [FE-0190.2.2] Optimize serialization for `NamedBuffer` and `NamedBitBuffer` (e.g., zero-copy if feasible).
    - [FE-0190.2.3] Preserve tree topology (parent/child relationships) during serialization.
- [FE-0190.3] **Lua API**
    - [FE-0190.3.1] Provide a `publishTree(topic, rootObject)` method.
    - [FE-0190.3.2] Provide a `receiveTree()` method (blocking or non-blocking).
- [FE-0190.4] **Performance**
    - [FE-0190.4.1] Minimize serialization overhead to support high-frequency updates (e.g., 1kHz for small trees).
    - [FE-0190.4.2] Support multi-part messages where the first part is the topic and the second part is the serialized tree.
- [FE-0190.5] **Integration**
    - [FE-0190.5.1] Organize components under the `quasar.zmq` Lua namespace.
    - [FE-0190.5.2] Integrate with the `scripting` plugin system via `registerPluginComponents`.

Project shall be located in `cmake-projects/scripting/plugins/zmq`.
