# Feature 0060

## Title

SMP Standard - Component Model & Interfaces

## Description

This feature covers the component model and object interfaces from ECSS-E-ST-40-07C Rev.1 (Section 5.2).

## Requirements

The following capabilities and features shall be provided:

- [FE-0060.1] Object Specification (IObject)
    - [FE-0060.1.1] (ECSS-E-ST-40-07_1630025) All SMP objects shall provide name, description, parent, and child collection features as per IObject.h.
    - [FE-0060.1.2] (ECSS-E-ST-40-07_1630026) All SMP objects with the same parent that are to be resolved by the Resolver shall have a unique name.
    - [FE-0060.1.3] (ECSS-E-ST-40-07_1630027) The validity of the SMP name shall be checked when an SMP object is created.
    - [FE-0060.1.4] (ECSS-E-ST-40-07_1630028) The Entry Points, Event Sinks, Event Sources, Fields, Properties, Operations, Containers, References, and Failures contained in an object shall have that object as their parent.
    - [FE-0060.1.5] (ECSS-E-ST-40-07_1630029) Name, Description and Parent of an SMP object shall never change during its lifetime.

- [FE-0060.2] Collection Specification (ICollection)
    - [FE-0060.2.1] (ECSS-E-ST-40-07_1630030) All SMP Collections of SMP elements shall implement the ICollection interface.
    - [FE-0060.2.2] (ECSS-E-ST-40-07_1630031) The ICollection at method shall return the element with the given position or name.
    - [FE-0060.2.3] (ECSS-E-ST-40-07_1630032) The ICollection size method shall return the number of elements.
    - [FE-0060.2.4] (ECSS-E-ST-40-07_1630033) The ICollection empty method shall return true if collection is empty.
    - [FE-0060.2.5] (ECSS-E-ST-40-07_1630034) The ICollection begin method shall return the collection begin iterator.
    - [FE-0060.2.6] (ECSS-E-ST-40-07_1630035) The ICollection end method shall return the collection end iterator.

- [FE-0060.3] Component Specification
    - [FE-0060.3.1] (ECSS-E-ST-40-07_1630036) All SMP Components shall implement the IComponent interface.
    - [FE-0060.3.2] (ECSS-E-ST-40-07_1630037) The IComponent GetState method shall return the current state of the component.
    - [FE-0060.3.3] (ECSS-E-ST-40-07_1630038) Table 5-2 defines the Component states: Created, Publishing, Configured, Connected, Disconnected.
    - [FE-0060.3.4] (ECSS-E-ST-40-07_1630039) The IComponent Publish method shall be used to publish fields, properties and operations.
    - [FE-0060.3.5] (ECSS-E-ST-40-07_1630040) The IComponent Configure method shall be used to perform initial configuration.
    - [FE-0060.3.6] (ECSS-E-ST-40-07_1630041) The IComponent Connect method shall allow connecting to the simulator environment.
    - [FE-0060.3.7] (ECSS-E-ST-40-07_1630042) The IComponent Disconnect method shall disconnect the component.
    - [FE-0060.3.8] (ECSS-E-ST-40-07_1630043) The IComponent GetField method shall provide access to fields.
    - [FE-0060.3.9] (ECSS-E-ST-40-07_1630044) The IComponent GetFields method shall return a collection of component fields.
    - [FE-0060.3.10] (ECSS-E-ST-40-07_1630045) The IComponent GetUuid method shall return the component UUID.
    - [FE-0060.3.11] (ECSS-E-ST-40-07_1630046) The IComponent GetSimpleValue method shall return a simple type value.
    - [FE-0060.3.12] (ECSS-E-ST-40-07_1630047) The IComponent SetSimpleValue method shall set a simple type value.
    - [FE-0060.3.13] (ECSS-E-ST-40-07_1630048) The IComponent GetSimpleArrayValue method shall return a simple array value.
    - [FE-0060.3.14] (ECSS-E-ST-40-07_1630049) The IComponent SetSimpleArrayValue method shall set a simple array value.
    - [FE-0060.3.15] (ECSS-E-ST-40-07_1630050) The IComponent AddChild method shall add a new child object.
    - [FE-0060.3.16] (ECSS-E-ST-40-07_1630051) The IComponent RemoveChild method shall remove a child object.
    - [FE-0060.3.17] (ECSS-E-ST-40-07_1630052) The IComponent IsChildInCollection method shall check for child existence.
    - [FE-0060.3.18] (ECSS-E-ST-40-07_1630053) Models shall implement the IModel interface.
    - [FE-0060.3.19] (ECSS-E-ST-40-07_1630054) Services shall implement the IService interface.
    - [FE-0060.3.20] (ECSS-E-ST-40-07_1630055) Services shall ensure their state is fully persisted.
    - [FE-0060.3.21] (ECSS-E-ST-40-07_1630056) Components requiring dynamic link removal shall implement ILinkingComponent.
    - [FE-0060.3.22] (ECSS-E-ST-40-07_1630057) The ILinkingComponent RemoveLinks method shall remove links to a component.

- [FE-0060.4] Aggregation
    - [FE-0060.4.1] (ECSS-E-ST-40-07_1630058) Components referencing other components shall implement IAggregate.
    - [FE-0060.4.2] (ECSS-E-ST-40-07_1630059) The IAggregate GetReference method shall return a reference by name.
    - [FE-0060.4.3] (ECSS-E-ST-40-07_1630060) The IAggregate GetReferences method shall return all references.
    - [FE-0060.4.4] (ECSS-E-ST-40-07_1630061) References shall implement IReference.
    - [FE-0060.4.5] (ECSS-E-ST-40-07_1630062) The IReference GetComponent method shall return a referenced component by name.
    - [FE-0060.4.6] (ECSS-E-ST-40-07_1630063) The IReference GetComponents method shall return all referenced components.
    - [FE-0060.4.7] (ECSS-E-ST-40-07_1630064) The IReference AddComponent method shall add a component reference.
    - [FE-0060.4.8] (ECSS-E-ST-40-07_1630065) The IReference RemoveComponent method shall remove a component reference.
    - [FE-0060.4.9] (ECSS-E-ST-40-07_1630066) The IReference GetCount method shall return the number of referenced components.
    - [FE-0060.4.10] (ECSS-E-ST-40-07_1630067) The IReference GetUpper method shall return the upper limit.
    - [FE-0060.4.11] (ECSS-E-ST-40-07_1630068) The IReference GetLower method shall return the lower bound.

- [FE-0060.5] Composition
    - [FE-0060.5.1] (ECSS-E-ST-40-07_1630069) Objects containing components shall implement IComposite.
    - [FE-0060.5.2] (ECSS-E-ST-40-07_1630070) The IComposite GetContainer method shall return a container by name.
    - [FE-0060.5.3] (ECSS-E-ST-40-07_1630071) The IComposite GetContainers method shall return all containers.
    - [FE-0060.5.4] (ECSS-E-ST-40-07_1630072) Objects representing composition of children shall implement IContainer.
    - [FE-0060.5.5] (ECSS-E-ST-40-07_1630073) The IContainer GetComponent method shall return a child component by name.
    - [FE-0060.5.6] (ECSS-E-ST-40-07_1630074) The IContainer GetComponents method shall return all child components.
    - [FE-0060.5.7] (ECSS-E-ST-40-07_1630075) The IContainer AddComponent method shall add a child component.
    - [FE-0060.5.8] (ECSS-E-ST-40-07_1630076) The IContainer GetCount method shall return the number of components.
    - [FE-0060.5.9] (ECSS-E-ST-40-07_1630077) The IContainer GetUpper method shall return the maximum number of components.
    - [FE-0060.5.10] (ECSS-E-ST-40-07_1630078) The IContainer GetLower method shall return the minimum number of components.
    - [FE-0060.5.11] (ECSS-E-ST-40-07_1630079) The IContainer DeleteComponent method shall delete a child component.

- [FE-0060.6] Events
    - [FE-0060.6.1] (ECSS-E-ST-40-07_1630080) Objects receiving event notifications shall implement IEventSink.
    - [FE-0060.6.2] (ECSS-E-ST-40-07_1630081) The IEventSink GetEventArgType method shall provide the expected argument type.
    - [FE-0060.6.3] (ECSS-E-ST-40-07_1630082) The IEventSink Notify method shall inform the object about the event.
    - [FE-0060.6.4] (ECSS-E-ST-40-07_1630083) Objects representing event sources shall implement IEventSource.
    - [FE-0060.6.5] (ECSS-E-ST-40-07_1630084) The IEventSource Subscribe method shall add an event sink.
    - [FE-0060.6.6] (ECSS-E-ST-40-07_1630085) The IEventSource Unsubscribe method shall remove an event sink.
    - [FE-0060.6.7] (ECSS-E-ST-40-07_1630086) Event source emitting an event shall call Notify on all subscribed sinks.
    - [FE-0060.6.8] (ECSS-E-ST-40-07_1630087) The IEventSource GetEventArgType method shall return the transmitted argument type.
    - [FE-0060.6.9] (ECSS-E-ST-40-07_1630088) The IEventSource GetEventSinks method shall return all subscribed sinks.
    - [FE-0060.6.10] (ECSS-E-ST-40-07_1630089) Components with external event sinks shall implement IEventConsumer.
    - [FE-0060.6.11] (ECSS-E-ST-40-07_1630090) The IEventConsumer GetEventSinks method shall return all contained event sinks.
    - [FE-0060.6.12] (ECSS-E-ST-40-07_1630091) The IEventConsumer GetEventSink method shall return a sink by name.
    - [FE-0060.6.13] (ECSS-E-ST-40-07_1630092) Components with external event sources shall implement IEventProvider.
    - [FE-0060.6.14] (ECSS-E-ST-40-07_1630093) The IEventProvider GetEventSources method shall return all contained event sources.
    - [FE-0060.6.15] (ECSS-E-ST-40-07_1630094) The IEventProvider GetEventSource method shall return a source by name.

- [FE-0060.7] Entry Points
    - [FE-0060.7.1] (ECSS-E-ST-40-07_1630095) Objects representing schedulable entry points shall implement IEntryPoint.
    - [FE-0060.7.2] (ECSS-E-ST-40-07_1630096) The IEntryPoint Execute method shall be called when triggered.
    - [FE-0060.7.3] (ECSS-E-ST-40-07_1630097) Components holding entry points shall implement IEntryPointPublisher.
    - [FE-0060.7.4] (ECSS-E-ST-40-07_1630098) The IEntryPointPublisher GetEntryPoints method shall return all entry points.
    - [FE-0060.7.5] (ECSS-E-ST-40-07_1630099) The IEntryPointPublisher GetEntryPoint method shall return an entry point by name.

- [FE-0060.8] Dynamic Invocation
    - [FE-0060.8.1] (ECSS-E-ST-40-07_1630100) Components allowing dynamic invocation shall implement IDynamicInvocation.
    - [FE-0060.8.2] (ECSS-E-ST-40-07_1630101) Callable operations and properties shall be registered via IPublication.
    - [FE-0060.8.3] (ECSS-E-ST-40-07_1630102) The IDynamicInvocation Invoke method shall invoke a method referenced by a request.
    - [FE-0060.8.4] (ECSS-E-ST-40-07_1630103) The IDynamicInvocation GetProperties method shall return invokable properties.
    - [FE-0060.8.5] (ECSS-E-ST-40-07_1630104) The IDynamicInvocation GetOperations method shall return invokable operations.
    - [FE-0060.8.6] (ECSS-E-ST-40-07_1630105) The IDynamicInvocation GetOperation method shall return an operation by name.
    - [FE-0060.8.7] (ECSS-E-ST-40-07_1630106) The IDynamicInvocation GetProperty method shall return a property by name.
    - [FE-0060.8.8] (ECSS-E-ST-40-07_1630107) Request objects shall implement IRequest.
    - [FE-0060.8.9] (ECSS-E-ST-40-07_1630108) The IRequest GetName method shall return the operation or property name.
    - [FE-0060.8.10] (ECSS-E-ST-40-07_1630109) The IRequest GetParameterCount method shall return the parameter count.
    - [FE-0060.8.11] (ECSS-E-ST-40-07_1630110) The IRequest GetParameterIndex method shall return a parameter index by name.
    - [FE-0060.8.12] (ECSS-E-ST-40-07_1630111) The IRequest SetParameterValue method shall set a parameter value.
    - [FE-0060.8.13] (ECSS-E-ST-40-07_1630112) The IRequest GetParameterValue method shall get a parameter value.
    - [FE-0060.8.14] (ECSS-E-ST-40-07_1630113) The IRequest SetReturnValue method shall set the return value.
    - [FE-0060.8.15] (ECSS-E-ST-40-07_1630114) The IRequest GetReturnValue method shall get the return value.
    - [FE-0060.8.16] (ECSS-E-ST-40-07_1630115) The IRequest GetType method shall return the request type.
    - [FE-0060.8.17] (ECSS-E-ST-40-07_1630116) Table 5-3 defines the Request Types: RT_Invoke, RT_Get, RT_Set.

- [FE-0060.9] Persistence
    - [FE-0060.9.1] (ECSS-E-ST-40-07_1630117) Objects needing self-persistence shall implement IPersist.
    - [FE-0060.9.2] (ECSS-E-ST-40-07_1630118) Reading and writing data shall be symmetrical.
    - [FE-0060.9.3] (ECSS-E-ST-40-07_1630119) The IPersist Restore method shall read persisted data.
    - [FE-0060.9.4] (ECSS-E-ST-40-07_1630120) The IPersist Store method shall write persisted data.

- [FE-0060.10] Failures
    - [FE-0060.10.1] (ECSS-E-ST-40-07_1630121) Objects representing failure shall implement IFailure.
    - [FE-0060.10.2] (ECSS-E-ST-40-07_1630122) The IFailure Fail method shall set state to failed.
    - [FE-0060.10.3] (ECSS-E-ST-40-07_1630123) The IFailure Unfail method shall set state to not failed.
    - [FE-0060.10.4] (ECSS-E-ST-40-07_1630124) The IFailure IsFailed method shall return the failure state.
    - [FE-0060.10.5] (ECSS-E-ST-40-07_1630125) Models with failures shall implement IFallibleModel.
    - [FE-0060.10.6] (ECSS-E-ST-40-07_1630126) The IFallibleModel GetFailures method shall return possible failures.
    - [FE-0060.10.7] (ECSS-E-ST-40-07_1630127) The IFallibleModel GetFailure method shall return a failure by name.
    - [FE-0060.10.8] (ECSS-E-ST-40-07_1630128) The IFallibleModel IsFailed method shall return the aggregated failure state.

- [FE-0060.11] Fields
    - [FE-0060.11.1] (ECSS-E-ST-40-07_1630129) Simple type fields shall implement ISimpleField.
    - [FE-0060.11.2] (ECSS-E-ST-40-07_1630130) The ISimpleField GetValue method shall return the field value.
    - [FE-0060.11.3] (ECSS-E-ST-40-07_1630131) The ISimpleField SetValue method shall set the field value.
    - [FE-0060.11.4] (ECSS-E-ST-40-07_1630132) The ISimpleField GetPrimitiveTypeKind method shall return the primitive type kind.
    - [FE-0060.11.5] (ECSS-E-ST-40-07_1630133) Structured fields shall implement IStructureField.
    - [FE-0060.11.6] (ECSS-E-ST-40-07_1630134) The IStructureField GetField method shall return a sub-field by name.
    - [FE-0060.11.7] (ECSS-E-ST-40-07_1630135) The IStructureField GetFields method shall return all sub-fields.
    - [FE-0060.11.8] (ECSS-E-ST-40-07_1630136) Array fields shall implement IArrayField.
    - [FE-0060.11.9] (ECSS-E-ST-40-07_1630137) The IArrayField GetItem method shall return an item as IField.
    - [FE-0060.11.10] (ECSS-E-ST-40-07_1630138) The IArrayField GetSize method shall return the array size.
    - [FE-0060.11.11] (ECSS-E-ST-40-07_1630139) Simple array fields shall implement ISimpleArrayField.
    - [FE-0060.11.12] (ECSS-E-ST-40-07_1630140) The ISimpleArrayField GetSize method shall return the number of items.
    - [FE-0060.11.13] (ECSS-E-ST-40-07_1630141) The ISimpleArrayField GetValue method shall return an item value.
    - [FE-0060.11.14] (ECSS-E-ST-40-07_1630142) The ISimpleArrayField SetValue method shall set an item value.
    - [FE-0060.11.15] (ECSS-E-ST-40-07_1630143) The ISimpleArrayField GetValues method shall return multiple item values.
    - [FE-0060.11.16] (ECSS-E-ST-40-07_1630144) The ISimpleArrayField SetValues method shall set multiple item values.
    - [FE-0060.11.17] (ECSS-E-ST-40-07_1630145) All fields shall implement IField.
    - [FE-0060.11.18] (ECSS-E-ST-40-07_1630146) The IField GetView method shall return the View Kind.
    - [FE-0060.11.19] (ECSS-E-ST-40-07_1630147) The IField IsState method shall return true if field is state.
    - [FE-0060.11.20] (ECSS-E-ST-40-07_1630148) The IField IsInput method shall return true if field is input.
    - [FE-0060.11.21] (ECSS-E-ST-40-07_1630149) The IField IsOutput method shall return true if field is output.
    - [FE-0060.11.22] (ECSS-E-ST-40-07_1630150) The IField GetType method shall return the field type.
    - [FE-0060.11.23] (ECSS-E-ST-40-07_1630151) Fields allowing forcing shall implement IForcibleField.
    - [FE-0060.11.24] (ECSS-E-ST-40-07_1630152) The IForcibleField Force method shall force the field value.
    - [FE-0060.11.25] (ECSS-E-ST-40-07_1630153) The IForcibleField Unforce method shall remove forcing.
    - [FE-0060.11.26] (ECSS-E-ST-40-07_1630154) The IForcibleField Freeze method shall freeze the field value.
    - [FE-0060.11.27] (ECSS-E-ST-40-07_1630155) The IForcibleField IsForced method shall return true if forced or frozen.
    - [FE-0060.11.28] (ECSS-E-ST-40-07_1630156) Output fields pushing data shall implement IOutputField.
    - [FE-0060.11.29] (ECSS-E-ST-40-07_1630157) The IOutputField Connect method shall connect to an input field.
    - [FE-0060.11.30] (ECSS-E-ST-40-07_1630158) The IOutputField Push method shall push the value to connected fields.
    - [FE-0060.11.31] (ECSS-E-ST-40-07_1630159) Table 5-4 defines semantically equivalent types for connections.
    - [FE-0060.11.32] (ECSS-E-ST-40-07_1630160) The IOutputField Disconnect method shall disconnect from an input field.
    - [FE-0060.11.33] (ECSS-E-ST-40-07_1630161) The IOutputField IsAutomatic method shall return true if push is automatic.
    - [FE-0060.11.34] (ECSS-E-ST-40-07_1630162) The IOutputField IsAutomatic method shall return false if push is performed by Simulation Environment.
    - [FE-0060.11.35] (ECSS-E-ST-40-07_1630163) If IsAutomatic returns true, Push shall be called on value change.
    - [FE-0060.11.36] (ECSS-E-ST-40-07_1630164) The IOutputField GetInputFields method shall return connected input fields.

- [FE-0060.12] Properties
    - [FE-0060.12.1] (ECSS-E-ST-40-07_1630172) The IProperty GetAccess method shall return the Access Kind.
    - [FE-0060.12.2] (ECSS-E-ST-40-07_1630173) Table 5-5 defines Property Access Kind values: Read/Write, Read-Only, Write-Only.
    - [FE-0060.12.3] (ECSS-E-ST-40-07_1630174) The IProperty GetView method shall return the View Kind.
    - [FE-0060.12.4] (ECSS-E-ST-40-07_1630175) The IProperty GetValue method shall return the property value.
    - [FE-0060.12.5] (ECSS-E-ST-40-07_1630176) The IProperty SetValue method shall set the property value.
    - [FE-0060.12.6] (ECSS-E-ST-40-07_1630177) The IProperty GetPrimitiveType method shall return the equivalent primitive type.

- [FE-0060.13] Operations
    - [FE-0060.13.1] (ECSS-E-ST-40-07_1630178) All SMP operations shall implement the IOperation interface.
    - [FE-0060.13.2] (ECSS-E-ST-40-07_1630179) The IOperation GetParameters method shall return parameters.
    - [FE-0060.13.3] (ECSS-E-ST-40-07_1630180) The IOperation GetParameter method shall return a parameter by name.
    - [FE-0060.13.4] (ECSS-E-ST-40-07_1630181) The IOperation GetReturnParameter method shall return the return parameter.
    - [FE-0060.13.5] (ECSS-E-ST-40-07_1630182) The IOperation GetView method shall return the View Kind.
    - [FE-0060.13.6] (ECSS-E-ST-40-07_1630183) The IOperation CreateRequest method shall return an IRequest object.
    - [FE-0060.13.7] (ECSS-E-ST-40-07_1630184) The IOperation Invoke method shall dynamically invoke the operation.
    - [FE-0060.13.8] (ECSS-E-ST-40-07_1630185) The IOperation DeleteRequest method shall delete an IRequest object.
    - [FE-0060.13.9] (ECSS-E-ST-40-07_1630186) The IParameter GetType method shall return the parameter type.
    - [FE-0060.13.10] (ECSS-E-ST-40-07_1630187) The IParameter GetDirection method shall return the parameter direction.
    - [FE-0060.13.11] (ECSS-E-ST-40-07_1630188) Table 5-6 defines Parameter Direction Kind values: In, Out, InOut, Return.
