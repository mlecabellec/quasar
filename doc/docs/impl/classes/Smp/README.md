# SMP Interfaces Documentation

This directory contains class documentation for Quasar's native SMP2 (ECSS-E-ST-40-07C) C++ abstractions:

- [AnySimple](AnySimple.md): Variant value container representing primitive SMP simple types.
- [Object](Object.md): Core SMP object metadata and hierarchy base class.
- [Publication](Publication/Publication.md): Field publication service interface implementation.
- [TypeRegistry](Publication/TypeRegistry.md): Type registration and discovery service implementation.
- [Simulator](Simulator.md): Root SMP2 simulation orchestration and service container.
- [Uuid](Uuid.md): 128-bit universally unique identifier value type.
